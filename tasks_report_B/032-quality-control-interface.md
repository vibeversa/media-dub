## Decisions Made
- **Segment-derived issues, not projection bodies:** `GET /projects/{id}/quality` is counts-only (`blockedCount/failedCount/codes[]`, never payload text) so it cannot supply R2 bodies; issues are one per `(segment, code)` from `GET /projects/{id}/segments` rows, projection is cross-check only, workspace supplies run status + `allowedActions`. Documented in `types.ts` header and `useQuality.ts`.
- **Display-only status mapping mirroring backend:** `statusForCode` maps `STALE→RetryRequired`, `SYNC_FAILURE→ManualReviewRequired`, `GAP/DRIFT/SILENCE/CROSSFADE→PassWithWarnings`, all other known QC codes (missing/overflow/overlap/voice/terminology/checksum/corrupt/rate/channel/loudness/clipping/peak/routing/placement/attenuation/unresolved)→`Blocked`; unknown `QC_*` (e.g. `QC_CUSTOM_UNKNOWN_XYZ`, `NOISY`) warn generically, never dropped. Client computes no scores—metric readout is segment timing as provided.
- **Passed equals clean segments:** `summarizeQuality` counts `warning/retry/review/blocked` from issues (`sum===totalIssues`) and `passed` as `totalSegments-flaggedSegments`, so R1 holds and zero-issue projects show an explicit passed celebration, not an empty list.
- **Quality key nests under project:** `quality.detail` is `['projects','detail',id,'quality']` (not a new top-level scope) so prefix invalidation cascades and no R1 scan change is needed; added to `run/stage/output` registry for live updates instead of polling.
- **Retry gating via workspace allowlist:** `processing.retry` in workspace `allowedActions` advertises the retry link (`POST /segments/{id}/retry`); otherwise the button is omitted with `title` reason tooltip, and review links use `/review?project=` deep-links (Task 031 has no cross-project list).
- **Evidence without new backend endpoints:** waveform is a local mini-canvas (deterministic bars, `rgb()` fill, no hex), timestamp jumps via `useTimelinePlayerStore.requestSeek`, audio reuses `usePreviewMedia` signed URL, artifact is optional `artifactUrl` from segment rows with single `invalidateQueries` refetch then `quality-evidence-unavailable` note; signed URLs never enter filter URLs.
