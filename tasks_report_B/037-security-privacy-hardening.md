## Decisions Made
- **Facades over rewrites (Review Fix gate):** per-endpoint authz, RLS, storage prefixes, 15-min presigned URLs, and `ConsentService.ValidateForVoice` already exist from feature tasks; the four task-named files delegate to them rather than forking semantics, so domain and service agree by construction.
- **Logout stays anonymous:** task text says "login/refresh/health only" but `AuthController.Logout` is intentionally idempotent-anonymous (unknown/expired token still 200); enumerated it explicitly with rationale instead of breaking session-clearing.
- **`MEMBERSHIP_REVOKED` not added:** the frozen `ErrorCodes` catalog has no such code; revoked membership fails closed as 403 `FORBIDDEN` (existing handler + `TenantGuard`), and the test asserts that mapping rather than inventing a code.
- **Additive query-key scoping:** re-shaping all existing keys to include `tenantId` would break 90+ call sites and prefix-invalidation tests; the opt-in `scopedTenantKey` wrapper proves tenant partitioning without touching the frozen nesting.
- **Narrow DTO secret scan:** session `AccessToken/RefreshToken` are auth artifacts (returned once at login by design), so the scan targets only provider/DB/storage fragments (`connectionstring/signingkey/apikey/...`) and passes.
- **Incomplete-evidence test via `Pending`:** `ConsentRecord` ctor validates required fields, so whitespace-evidence rows cannot be constructed; the `Unknown` path is proven with `Pending` status (plus null-record cases) while the gate keeps its defensive whitespace checks.
