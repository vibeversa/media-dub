## Decisions Made
- **File-vs-directory coexistence:** kept `hooks/useProgressStream.ts` (file) alongside `hooks/useProgressStream/` (test dir); names differ by `.ts` suffix so both exist on Linux.
- **Cursor is equality-based, never lexical/timestamp:** backend `SseEnvelope.EventId` is `Guid.NewGuid().ToString("N")` (random, no order); `SseCursorTracker.shouldProcess()` dedupes via `Set.has()`, `markSeen()` advances `lastCursor`; `occurredAt` never read (clock-skew irrelevant).
- **Header-only auth:** `buildProgressStreamUrl()` never appends `?access_token=`; `fetch` sends `Authorization: Bearer <token>` from `getTokenOrUndefined()` + `Accept: text/event-stream` + `Last-Event-ID` when cursor present; 401 calls `emitAuthExpired()` for Task 019.
- **404 stops:** `response.status===404` sets `stoppedRef=true`, `streamState='stopped'`, invalidates `queryKeys.workspace.detail(projectId)`, no retry timer.
- **Completion→badge augmentation:** `resolveInvalidations()` merges `queryKeyRegistry` keys with `queryKeys.notifications.list()` + `unreadCount()` when `COMPLETION_SSE_TYPES` (`run.status_changed`/`stage.completed`/`stage.failed`/`output.ready`/`export.completed`/`export.failed`) matches; `stage.progress` intentionally omits badge to avoid churn.
- **Debounce 500ms:** `pending: Map<string,QueryKey>` keyed by `JSON.stringify(key)`, single `setTimeout(INVALIDATION_DEBOUNCE_MS)` per burst; flush calls `invalidateQueries` once per unique key.
- **Backoff:** `computeSseBackoffMs(attempt, random=Math.random()) = min(30000, 1000*2^attempt + floor(random*1000))`; fallback threshold `SSE_MAX_FAILURES_BEFORE_POLL=3`; `POLL_ACTIVE_VISIBLE_MS=3000`, `POLL_HIDDEN_MS=20000`.
- **Approximate display:** `formatApproximatePercent()` clamps/rounds with `~` prefix; `workspace.json:header.progressValue="~{{percent}}% complete"` + `progressApproximateNote="Progress is approximate."` rendered as `workspace-progress-approx`; E2E asserts `~` and `approximate` substrings (existing `42%` substring assertions still pass).
- **Shell badge wiring (minimal, not full center):** `AppShell({unreadCount})` renders `NotificationBell` directly when prop defined (tests), else `LiveNotificationBell` (`useQuery(queryKeys.notifications.unreadCount(), apiClient.getUnreadNotificationCount, enabled=useIsAuthenticated())`); no Task 034 center UI added.
- **E2E bar event choice:** `stage.progress` does NOT invalidate workspace (registry), so bar test emits `stage.completed` (invalidates both) and bumps `workspacePercent` 42→80 on second `workspaceCalls`.
