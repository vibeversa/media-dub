## Decisions Made
- **New catalog codes vs marker reuse:** Task 004 froze service markers (`VOICE_CONSENT_REQUIRED`→`CONSENT_REQUIRED`/403, `PREVIEW_QUOTA_EXCEEDED`→`QUOTA_EXCEEDED`/429, `PREVIEW_TEXT_INVALID`→`VALIDATION_FAILED`/400) and `PreviewArtifactTests` asserts them; HTTP layer needs distinct public codes per Task 010 spec, so the controller catches service exceptions and rethrows typed API exceptions (same 009 pattern). Service codes untouched.
- **New `SpeakerVoiceChanged` contract (19→20):** R4 requires a published dependent-invalidation event; no existing contract fits speaker scope (`SegmentSelectionChanged` is segment-scoped, `VoicePreviewCompleted` is job-terminal). Created the 20th frozen-envelope message and updated `MessageContractTests`; publisher mirrors the segment-selection MassTransit pattern (propagate after commit).
- **Project-stable single row via delete-then-insert:** `speaker_voice_assignments` is unique on (tenant, run, speaker) with no FK, so the service deletes all rows for (tenant, project, speaker) and inserts one scoped to the latest run (or the projectId as pseudo-run when runless). Guarantees `COUNT==1` for the stable-invariant test; history survives in audit events. Future per-run `VoiceAssignmentService.AssignAsync` copies forward via its prior-project lookup.
- **Voice ref accepts 3 shapes:** public `voice_` id, raw `D`/`N` GUID (by `VoiceProfile.Id`), or inventory `VoiceId` string (latest row). Unknown/cross-tenant →404 `VOICE_NOT_FOUND` (no leak). Preview `speakerId` accepts `spk_` or raw GUID; preview `text` defaults to a sample line when omitted.
- **Compatibility data model:** `VoiceProfile` has no sample-rate/channel/gender/style columns, so floors/tags parse from `ModelRefJson` (`sampleRateHz|sampleRate|sample_rate`, `channels|channelCount`, `gender`, `styleTags|styles|tags`) with absent-fields-pass for backward compat; project allowlists/floors parse from `SettingsJson` (`allowedVoiceStyles|voiceStyles|styleAllowlist`, `allowedGenders`, `voiceSampleRateFloor|voiceChannelsFloor`) with malformed-JSON→no-constraint. Cloning requirement is structural (`Type==Cloned` or `CloningEnabled`) plus live consent row plus global `Voices:CloningEnabled` kill-switch.
- **Preview HTTP mapping:** `VoicePreviewService` idempotency (`IsDuplicate`) →200 replay else 202; consent marker→403 `VOICE_CONSENT_REQUIRED`; quota marker→429 `PREVIEW_QUOTA_EXCEEDED`; text marker→400 `PREVIEW_TEXT_INVALID`; voice `NotFoundException`→404 `VOICE_NOT_FOUND`. No `IdempotencyFilter` on preview create (service owns the `(TenantId, Key)` namespace; a filter would double-namespace). Detail mints a 15-minute presigned URL only when Completed; storage failures degrade to null URL (status stays truthful).
- **Authz:** GETs `RequireProjectViewer` (`project.view`), assignment + preview create `RequireProjectEditor` (`project.edit`); project-tenant mismatch 403, speaker/voice/preview mismatch 404. Same-voice PUT is a 200 no-op with no publish and no audit row.
