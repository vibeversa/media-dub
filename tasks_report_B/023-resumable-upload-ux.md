## Decisions Made
- **Bundle is authority, backend divergence flagged not fixed:** the hand-authored bundle types uploads as `initiateUpload({fileName,contentType,sizeBytes,partCount})→UploadSession` + single-`partNumber` authorize, while `UploadsController` speaks `CreateUploadRequest{FileName,ContentType,DeclaredSize,…}` + `PartNumbers[]`. Per the frozen-bundle rule and generated-types mandate, the engine uses the generated client exactly; reconciling bundle↔controller is a backend/bundle task outside this frontend scope (recorded for 024/025).
- **No per-part checksums on the wire:** the backend requires none (S3 ETags authoritative on complete); the client hash serves duplicate detection + resume identity only. Stated in code so nobody "adds" a checksum protocol the server doesn't speak.
- **Honest progress:** `fetch` exposes no upload-progress events, so per-part bars are discrete states and the overall bar counts acknowledged bytes only — no faked percentages.
- **Validation/analysis split is derived, documented:** the bundle exposes no "analysis running" flag, so `validating`→`analyzing` flips after 3 non-terminal polls; terminal `MediaReady`/`MediaRejected`/`Duplicate`/`Expired` always win. The derivation lives in pure `deriveValidationOutcome`, unit-tested.
- **No MSW (repo convention over task text):** Task 023 suggests MSW, but Task 017 bans it — all tests use `setInnerFetchForTests` (PUTs pass the interceptor untouched as non-API URLs) and Playwright `page.route`, matching every prior suite.
- **No new query keys:** the engine polls imperatively; terminal states invalidate the existing `queryKeys.workspace.detail()`/`project.detail()` factories (R1 scan stays clean).
- **Reattach does not auto-resume:** after refresh the user picks the file (fingerprint-checked), sees reconciled counts in `paused`, and presses Resume — explicit, testable, no surprise uploads.
- **E2E timing made invariant-based:** exact PUT-count assertions were replaced with per-part attempt bounds (1–2) after observing legitimate authorize-order interleaves.
