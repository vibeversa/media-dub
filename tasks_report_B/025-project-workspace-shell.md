## Decisions Made
- **Full backend shape despite minimal generated type:** frozen `Workspace` exposes only project/progress/permissions/warnings, but `WorkspaceService.GetAsync` returns 12 sections (project/media/run/phase/stage/progress/review/warnings/output/cost/activity/permissions). `parseWorkspace` reads via `Record<string,unknown>` with camelCase+PascalCase `pick` and `configHash`/`configurationHash`, `allowedActions` array-or-object, `activity.recent`/`items`, warning string-or-object coercion — no `api/generated` deep import, no thrown on optional sections (missing project rejects).
- **Phase projection UI-only, no time predictions:** fixed `PIPELINE_PHASES` (validation/speech/translation/voice/timing/mix/qc/render) marked done/active/pending/failed from aggregate phase/stage/run; translation+voice share one parallel branch (both active when either current) per `StageGraph` (VoiceAssignment after Diarization joining Translation at VoiceGeneration); only `progress.updatedAt` rendered via `formatDate`, never countdowns. Banned-word hygiene enforced case-sensitive (`detail` contains lowercase `eta` but not uppercase `ETA`, so safe).
- **Version skew as hash drift:** no aggregate version field exists, so skew = `run.configHash !== project.configHash` (mirrors `CONFIG_CHANGED_SINCE_RUN`); stale banner also shows on background `isFetching` with data + `workspace-refresh` calling `refetch`.
- **Header actions narrowed to six:** `getWorkspaceActions` maps allowlist to `open` (project.view→`./media` link), `cancel` (processing.cancel+active run), `retry` (processing.retry+failed), `export` (export.create/download+output ready→`./exports` link), `delete` (project.delete), `archive` (project.edit, label flips unarchive when `isArchived`); cancel/retry/delete/archive wired with `useAppMutation`+`newIdempotencyKey`+`queryKeys.workspace.detail` invalidation, open/export are `Link`s that also `setSelectedTab`.
- **Cost gating mirrors dashboard:** `hasAdminPermission(session)` OR allowlist `admin.manage`/`diagnostics.view`; hidden with no error flash. Review deep link targets global `/review`, quality/output/activity target `./quality`/`./exports`/`./activity` (router still maps tabs to `ProjectDetailsPage`, so URL change + details shell is the navigation assert).
- **E2E mock updates are required, not drive-bys:** `ProjectDetailsPage` gaining a fetch breaks hermetic suites that 404 unknown routes (`dashboard` redirected, `auth` lost details). Added minimal `/workspace` 200 fixtures to those two suites; `projects`/`processing-start` already return 200 envelopes for workspace-shaped URLs (list envelope → non-`NOT_FOUND` error, no redirect) so left untouched.
