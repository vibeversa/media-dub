## Decisions Made
- **Cross-tenant stays 403, not spec R6 404:** established `ProjectOwnershipHandler` (tenant-mismatch → 403) + `ProjectsUploadsApiTests.Cross_Tenant_403` + `AdminController` docs ("matching project controllers") all pin 403. Switching `GetAsync` to 404 would also split behavior (`prj_` 404 vs raw-GUID 403 via handler pre-check, which only parses raw GUIDs). New test asserts 403 `FORBIDDEN` and documents the deviation; tenant isolation still holds (no data leak).
- **Missing/deleted uses new `PROJECT_NOT_FOUND` (404):** safe because no existing test asserts `NOT_FOUND` for projects; gives the spec's machine-readable code without touching the 403 path.
- **`Name` optional (absent → Untitled), not strictly required:** spec says required, but existing `CreateProjectRequest`/tests create without names and expect success. Enforce 1..200 only when present (empty/overlong → 400); duplicates allowed. Same compat rationale for list default `createdAt desc` (new) while keeping old `ListAsync` asc untouched.
- **List envelope is a superset:** spec wants `{items,page,pageSize,total,sort,sortDir}`; we return that plus `hasMore` (backward compat with `PaginatedResult`) and `clamped` (spec's `pageSize>100` hint). `archived` modes: absent/`false`→active only, `true`→archived only, `all`→both; invalid sort/dir/archived/owner → 400, no silent fallback.
- **PATCH strictness:** raw `JsonElement` inspection; allowed keys `name,description,settings,processingSettings,settingsVersion` (case-insensitive); `targetLanguage`/`sourceLanguage` present → 400 `LANGUAGE_IMMUTABLE` (source included as same rationale); unknown → 400 with no partial apply (service validates before mutating). `description: null` ≡ absent (clearing unsupported); `settings: null` → 400. Version from `If-Match` (quoted/`W/`/`*` tolerant) wins, else body `settingsVersion`; header/body mismatch → 409.
- **Hash/version semantics:** any `settings`/`processingSettings` change recomputes via `ProjectConfigHash`; version bumps only on `processingSettings` change. `ConfigurationHash` mutators added to domain because none existed (`SettingsJson`/`ConfigurationHash` had no setters).
- **Dashboard quota = projects-per-day:** spec's `quota{remaining,resetsAt}` is ambiguous; implemented as `MaxProjectsPerDay - todayCount` with `resetsAt` = next UTC midnight. Storage = committed `ContentObject` bytes vs `Quota:MaxStorageBytes`; cost = month-to-date Reserved+Actual USD (no invoice detail).
