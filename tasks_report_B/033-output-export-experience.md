## Decisions Made
- **Allowlist single-source in `types.ts`, zero literals in dialog:** backend exposes no allowlist endpoint; `EXPORT_FORMAT_ALLOWLIST` (`srt|webvtt|json-timeline|speaker-metadata|transcript|translation|quality-report`) mirrors `ExportFormatParser.TryParse`+`ToWireName` kebab names, `EXPORT_TYPE_ALLOWLIST` (`audio|video|subtitles|manifest`) groups `OutputItemsDto` kinds for UX, `EXPORT_SCOPE_ALLOWLIST` (`full|segment-range|per-speaker`) filters via `advertisedScopes(output)`. `ExportCard.tsx` imports them and renders options dynamically — source scan test asserts no `"srt"`-style literals. Stale bundle `Srt|Vtt|Mp4|Wav|Mp3` normalizes (`Vtt→webvtt`) but `Mp4/Wav/Mp3` are rejected as not allowlisted.
- **Type/scope/run map to `{format,profile?,allowPartial?}` only:** the server accepts only `format`+`profile`+`allowPartial`; `profile` derives as kebab `type` (scope `full`) or `type-scope` (max 64, no traversal) via `profileForRequest`, `runId` is informational (server picks latest eligible run, validated against `availableRunIds` but never sent). Documented in `types.ts` header and `ExportCard.tsx`.
- **Formats unfiltered by type:** every `formatsForType(type)` returns the full allowlist (server validates `format` independently); per-type subsets would invent backend rules and risk empty allowlists. Empty `availableFormats=[]` prop still triggers the misconfig `EmptyState` with submit hidden.
- **Outputs key nests under project:** `outputs.detail` is `['projects','detail',id,'outputs']` (not top-level) plus new `runs.list` for the selector, so prefix invalidation cascades and no R1 scan change is needed; added `outputs.detail` to `run/stage/export/output` registry instead of polling.
- **Click-time means no query for URLs:** `fetchExportDownloadUrl` is a direct `apiClient.downloadExport` call (302 `Location`), never a `useQuery`, never in state/filter URLs; `requestRaw` throws for 410/404 so both returned and thrown expiries refetch exactly once, double-410 shows retry, 404 toasts `This export no longer exists` + `invalidateExports` so the row drops on refetch. Output assets use aggregate URLs directly (backend provides them) with a refresh button; exports never use them.
- **Retry gating via UX-hint permissions:** `ExportRow` shows retry only when `useAppStore.permissions` includes `export.create` (backend has no export-retry endpoint; retry re-posts `{format,allowPartial}`); otherwise a `title` reason tooltip. Review links use `/quality` deep-links (Task 032 owns QC).
