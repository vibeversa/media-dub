## Decisions Made
- **Draft + explicit Save over per-field auto-save:** R4 requires a save/discard/cancel guard, which is impossible with immediate PUTs. Chose draft state with `collectDirtyKeys` + global Save/Discard; only dirty keys are sent for per-key last-write-wins. Updated the old auto-save unit/E2E expectations accordingly and preserved all input testids.
- **System theme via resolved store value:** Store `ThemeName` stays `light|dark`; preference `ThemePreference` adds `system` resolved by `resolveEffectiveTheme()` (`matchMedia('(prefers-color-scheme: dark)')`, safe fallback `light` in jsdom). `applyPreferencesThroughHelpers()` writes the resolved value so `ThemeProvider` (`data-theme`) updates without reload; rollback restores the snapshot on failure.
- **Timezone as select + UTC fallback:** Replaced free-text with `TIMEZONE_OPTIONS` select (UTC first). Invalid stored values normalize to UTC with `settings-timezone-warning` + `settings-timezone-use-utc`; invalid draft blocks save with inline error + suggestion, matching the “400 → inline + UTC suggestion” contract without needing a backend 400.
- **Guard without `useBlocker`:** `useBlocker` throws in `MemoryRouter` unit tests. Implemented `requestLeave` + `settings-back-link` + `beforeunload` + dirty bar; dialog offers save/discard/cancel and is fully unit/E2E testable. Global header nav is covered by the visible dirty bar (no silent loss) plus `beforeunload` on reload.
- **Conflict/offline keep draft, never auto-resubmit:** 409 → invalidate + `refetch()` + `settings-conflict` with Retry/Refresh/Use-server; offline (`NETWORK_ERROR` or `navigator.onLine===false`) → `settings-offline` with queued Retry. Both preserve draft and roll back optimistic cache/store.
- **Channels future-only as disabled UI:** `NOTIFICATION_CHANNELS=['in-app','email','webhook']`; email/webhook render disabled with “(coming soon)” + `settings-channels-note` explaining in-app only. No backend key added.
- **Cost split cleanup now:** Deleted the four legacy `settings/` cost files per 035A handoff; `settings/types.ts` no longer exports cost helpers. `activity.test.tsx` re-pointed to `cost/`; no production code imported the deleted paths (`ActivityPage` already used `cost/`).
