## Decisions Made
- **No new error code:** `ADMIN_ROUTE_UNKNOWN` rides as a message marker on public `NOT_FOUND` (404) and `DIAGNOSTICS_FORBIDDEN` stays a marker on `FORBIDDEN`, following the preview-service precedent — catalog stays 65, no count-test churn.
- **Provider timeout stays 504:** spec's "502 (`PREVIEW_PROVIDER_TIMEOUT`)" is the marker name, not a status override; status follows the catalog (`ProviderTimeout` 504, `ProviderFailed/InvalidResponse` 502). `INTERNAL` reads as catalog `INTERNAL_ERROR`.
- **Orphans use cursor pagination:** service returns `OrphanArtifactPage` (opaque skip cursor), so the endpoint exposes `?pageSize&cursor` (default 50/max 200) rather than faking a total for `PaginatedResult`; leases use page-based slicing, DLQ paginates `TopReasons` while depth/oldest stay totals.
- **Replay is headers-only:** missed envelopes resend `ToHeaderOnlyFrame` (ids + correlation, no payload backfill); unknown cursor with a full 100-window sets `replayTruncated:true` and the client polls (026).
- **Elevated check is roles-first:** JWT `TenantAdmin/Service/Operator` pass immediately; otherwise resolved permissions must contain `admin.manage|diagnostics.view` (ProjectOwner grants `diagnostics.view`), then the Task 005 service guard re-checks membership. New admin endpoints require GUID `sub` (401 otherwise, per notifications precedent); legacy admin routes untouched.
- **Cross-tenant per-resource reads are 404:** `LoadOwnedAsync` now throws `NotFoundException` (was `ForbiddenException`) per the 013 no-leak mapping principle; no existing test asserted the old 403.
