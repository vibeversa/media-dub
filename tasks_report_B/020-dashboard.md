## Decisions Made
- **Backend is authority on shape:** `projectCounts` is `{active, archived, total}` (no in-review/failed/completed split), `recentOutputs`/`warnings` are generic `Record<string,unknown>[]`, quota is `{remaining, resetsAt}` (projects-per-day) while the ≥80% meter applies to `storage.usedBytes/quotaBytes`. Counts card shows total/active/archived; failed/review pressure surfaces via warnings + backlog — no extra aggregate calls (R1).
- **Partial = defensive sections, not extra calls:** one network call can only wholly succeed/fail, so R3 is implemented as per-section validation — any missing/invalid slice renders a per-card error with retry (`refetch` of the single query), rest renders. Tests inject partials by omitting sections (no MSW: repo has no MSW by Task 017 decision; `setInnerFetchForTests` is the seam, documented in report).
- **Empty-tenant CTA → `/projects`:** the Task 022 creation wizard does not exist yet; the tenant project list is its entry point, so the CTA links to the existing `/projects` route (verified navigable in unit + E2E) with a comment pointing 022 at it. A `/projects/new` link would 404 today.
- **Usage gating = `hasAdminPermission`:** spec says cost/quota render "only with permission" without naming it; reused the Task 018 Admin aliases (`admin.manage`/`diagnostics.view`/`admin:read`) since cost/quota are admin-grade aggregates. Hidden = `null` with no error flash.
- **Drill-downs use only existing routes:** stats/warnings-jobs → `/projects`, outputs/warning-rows → `/projects/:id`, reviews → `/review`, quota/storage manage → `/settings` (Admin usage detail lands in Task 036). No placeholder routes introduced.
- **Stale = `data !== undefined && isFetching`:** React Query has no 304 surface; background refetch indicator covers it. Unit test seeds `queryClient` + fires `void invalidateQueries` (not awaited — awaiting hangs on the gated fetch).
- **R1-scan comment trap:** the doc comment "`queryKey:` literals" matched the scan regex (colon + backtick); reworded to "queryKey literals" (no colon). Factory call `queryKey: queryKeys.dashboard.summary()` itself is legal.
- **Router-test QueryProvider:** added shared-provider wrapper + cache clear; no test deleted, assertions unchanged.
