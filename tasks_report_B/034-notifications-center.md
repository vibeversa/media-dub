## Decisions Made
- **Two files for step 1 (`useNotifications.ts` + `useUnreadCount.ts`):** task text lists both paths; `useNotifications.ts` owns the list query + `fetchUnreadCount` core, `useUnreadCount.ts` owns the badge query. Both use `queryKeys.notifications.list/unreadCount()` factory only, never literals.
- **Deep-link table mirrors `NotificationsController` + `NotificationEventMapper`:** `ProcessingCompleted/Failed`+`ProcessingRun`→`/projects/:id`, `ManualReviewRequired/ReviewResolved`+`ReviewItem`→`/review?project=:id&reviewId=:rid` (studio reads `project` param; `reviewId` is forward-compatible selection hint), `ExportCompleted/Failed`+`ExportJob`→`/projects/:id/exports`, `UploadRejected`+`MediaAsset`→`/projects/:id/media`, `DubbingProject`→`/projects/:id|:resourceId`, `Tenant`/`QuotaWarning`/`ProviderPolicyWarning` with project→`/projects/:id` else `/dashboard`, unknown→`/dashboard`. All segments `encodeURIComponent`.
- **`GoneState` via `deletedIds` prop + `deleted|gone|missing` sentinel:** backend has no deleted flag; `notificationLinkFor` returns `kind:'gone'` for `isDeletedTargetId(resourceId|projectId)`, `NotificationItem` renders inline `notifications-gone-{id}` with explanation + project/dashboard fallback instead of a link, row retained as read. Production passes `[]`; tests pass `['ntf_2']`.
- **Prefs value is a JSON string under one key:** generated `PreferencesResponse` is `Record<string,string>` (openapi `additionalProperties:string`); `serializeNotificationPrefs` stores `JSON.stringify(Record<Type,boolean>)` under `notificationPreferences`, `parseNotificationPrefs` accepts boolean/string/number variants, defaults all `true`. Toggles `PUT` immediately with rollback; list untouched (delivery-only).
- **SSE is hint-only with no new endpoint:** only `GET .../progress/stream` exists; Task 026 registry already invalidates notifications on `notification.created`. `useNotificationStream` adds the notification-scoped dedupe + `window` hint bus (`notifications:created`) for hermetic tests/future global streams, never polls, never mirrors rows. `extractNotificationId` reads only `notificationId|notification_id|id` from `payload`.
- **Badge cache collision fix:** `AppShell.LiveNotificationBell` previously cached `UnreadCountResponse` object under `queryKeys.notifications.unreadCount()` while `useUnreadCount` caches `number`; `String(object)` rendered `[object Object] unread` in E2E. Fixed by switching the shell to `fetchUnreadCount(signal)` (number) plus defensive `typeof raw === 'number' ? raw : raw?.unreadCount` in both shell and center.
- **No polling, 409 fallback:** list + unread use `staleTime:30_000`, all refetch flags `false`; unread 409 shows `notifications-unread-conflict` + `notifications-unread-retry` which invalidates `queryKeys.notifications.list({page:1,pageSize:20})` and refetches unread.
