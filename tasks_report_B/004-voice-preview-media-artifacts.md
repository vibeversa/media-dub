## Decisions Made
- **No new public error codes (stays 29):** `ErrorCodes.All` is frozen until Task 013 and `ErrorEnvelopeTests` pins it. Mapping: `PREVIEW_STATE_CONFLICT`→`Conflict`/409, `PREVIEW_QUOTA_EXCEEDED`→`QuotaExceeded`/429 (daily cap and per-minute throttle share it), `VOICE_CONSENT_REQUIRED`→`ConsentRequired`/403, `PREVIEW_TEXT_INVALID`→`ValidationFailed`/400, `PREVIEW_PROVIDER_TIMEOUT`→`ProviderTimeout`/504, `PREVIEW_PROVIDER_FAILED`→`ProviderFailed`/502. Task 010 endpoints can switch on the markers.
- **`ArtifactType`, not `ContentObject.Purpose`:** no `Purpose` column exists on `ContentObject` (adding one means altering a hot table plus backfill semantics for all existing rows). Preview purpose is carried by `Artifact.Type` + `Artifact.MetadataJson(durationMs, sampleRate, resolutions, sourceMediaId)` — the purpose-carrying record by existing design; `ContentObject` stays the content-addressed blob. R4 holds via fresh tenant-scoped rows per preview (test asserts preview content ids never equal the source id).
- **Synchronous service-driven synthesis, no request-queue consumer:** adding a `VoicePreviewRequested` durable contract + worker would double failure modes for a lane whose point is speed. `RequestPreviewAsync` drives `Pending→Running→terminal` inline via `ITtsProvider` (mock adapter, same as `TtsService`); idempotency-key dedup + terminal-state guards give at-least-once safety; `VoicePreviewCompleted` flows through the existing MassTransit+outbox pipeline for Task 010. A worker-side synthesis consumer can be added later without schema change.
- **Denied/blocked rows are persisted, then the coded exception throws:** consent blocks (`Blocked`) and quota denials (`Denied` + reason) become `Failed` rows with no provider call, so the audit trail is complete; callers still get 403/429. Denied rows count toward caps (prevents retry-spam bypass). Duplicate keys on denied/failed rows return existing (200 semantics, no second call).
- **Consent gate = kill-switch + live record check:** cloned voices require `VoiceOptions.CloningEnabled` AND a `Granted`, unrevoked `ConsentRecord` covering project+voice via `ConsentService.ValidateForVoice(..., policy: null)`; stock voices skip consent (`Verified` vacuously). Voice ids are inventory keys matched per-tenant; URL-shaped values rejected (SSRF guard).
- **`ProviderExecution.ProcessingRunId` falls back to the job id** when no run is passed (ad-hoc UI previews have no run); `ExternalJobId` carries the mock job ref when present; `VoiceProfileVersion` links the voice. Real (non-mock) provider voices fail fast with `PROVIDER_CONFIGURATION_ERROR` — preview lane wires the mock adapter only.
- **Preview bytes are honest local synthesis:** `MediaPreviewAudio`/`VoicePreviewAudio` persist deterministic sine WAVs (`audio/wav`), peaks persist real computed JSON; `VideoPreview` persists a JSON reservation manifest (`application/json`, never fake-mp4 bytes) and only when a video track exists AND `Preview:VideoPreviewEnabled` is true (this is the plan flag `preview.video.enabled`; `Application` has no `IConfiguration` reference so the mapping lives in `PreviewOptions`). Byte-level proxy transcode is an explicit later-task seam; artifact shapes are final.
- **Hook placement is service-level, optional, guarded:** `MediaAnalysisService`/`AudioPreparationService` take optional `MediaPreviewGenerator?` (existing constructions compile unchanged; DI injects it in the worker host). The hook runs after `CompleteAsync`, appends nothing to `StageCompleted.OutputArtifactIds` (preview stays decoupled from final audio), and both the generator contract (non-throwing) and a `CA1031`-justified guard ensure the parent can never fail on previews.
- **QC evidence lives in `QualityResult.DetailsJson.evidence[kind]` + `ArtifactId`:** single-column `ArtifactId` holds the latest link; the JSON map holds per-kind ids for `(TenantId, QcIssueId, ArtifactKind)` dedupe; reruns return the stored artifact with no new rows; unparsable details are replaced (evidence map authoritative).
