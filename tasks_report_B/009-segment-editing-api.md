## Decisions Made
- **New codes vs marker reuse:** Task 003 froze service codes (`CONFLICT`+`SELECTION_CONFLICT` marker, `NOT_FOUND`+`VERSION_NOT_FOUND`, `VALIDATION_FAILED`+`VERSION_SEGMENT_MISMATCH`) and `SelectionConcurrencyTests` asserts them; HTTP layer needs distinct public codes, so controller catches service exceptions and rethrows typed API exceptions (`SegmentSelectionConflictException`→`SelectionConflictApiException` with versions, `NotFound+marker`→`VersionNotFoundApiException`, `Domain+mismatch-marker`→`VersionSegmentMismatchApiException`, `Domain+non-empty-text`→`SegmentTextEmptyApiException`). Service codes untouched.
- **Details via interface, not manual returns:** created `IErrorDetailsProvider` so middleware serializes `error.details` camelCase consistently (409 refresh `{currentSelectionVersion,currentVersionIds:{transcriptVersionId,translationVersionId}}`, retry-active `{executionId,stage,attempt}`); controllers throw, never hand-build envelopes.
- **Cross-tenant segment →404, project →403:** `LoadOwnedSegmentAsync` throws `NotFoundException` on tenant/project mismatch (no leak) while `RequireProjectAsync` keeps 403 for project-tenant mismatch per Task 007; test asserts both (project 403, foreign segment under own project 404).
- **Retry authz:** changed `POST retry` from `RequireProjectOwner` to `RequireProjectEditor` (TenantAdmin/Owner/Editor/Service) because `processing.retry` is held by Editor+ per `RoleMatrix`/`PermissionResolver`; Owner-only would wrongly deny Editors. GETs stay `RequireProjectViewer` (includes Viewer who holds `review.view`); mutations `RequireProjectEditor` (`project.edit`).
- **Retry-active definition:** `Pending|Scheduled|Running|RetryPending` `StageExecution` for `(run,segment)` →409 `SEGMENT_RETRY_ACTIVE` with existing `{executionId,stage,attempt}`; second poll returns same id (idempotent). Pre-check runs before `RetryService` so no new attempt is minted on conflict.
- **List pagination diverges from `PaginationParams`:** segments use default 50/max 200 (not 20/100) via `NormalizeSegmentPaging`; sort fixed `startMs,Sequence` ascending; `pageSize=500` clamps to 200 in response.
- **Filter semantics frozen:** `speakerId` exact GUID/`spk_`; `reviewStatus` exact `ReviewStatus` name else 400; `qualityFlag` tries `QualityStatus` enum else exact `Code` case-insensitive; `syncIssue` accepts `true|false` (true=has non-`SyncAcceptable`, false=no issue) or `SyncStatus` name else 400; `text` `ILike %term%` over transcript `Text` + translation `PrimaryText` (escaped); `startMs/endMs` overlap (`StartMs<end && EndMs>start`, one-sided when single bound); all ANDed; batched post-load (selections/reviews/quality/sync) avoids N+1.
- **Text sanitization:** `RequireManualText` now strips HTML before trim/length (plain-text store); controller `RequireEditText` pre-rejects empty→`SEGMENT_TEXT_EMPTY` and overlong→`VALIDATION_FAILED` (fail-closed: tags count in pre-check, stripped length in service).
- **Audit:** selections rely on service audit (now with old IDs + `correlationId` passed from `X-Correlation-Id`/generated id); retry audits controller-owned (`processing.retry`, `segment` resource, `{stage,attempt,invalidated,correlationId}`); logs carry ids+correlationId only, never texts.
