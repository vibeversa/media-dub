## Decisions Made
- **No backend `actions[]` exists for projects** (only review context carries one): `getAllowedActions` is a pure function of status + `isArchived` + `/me` permission hints mirroring server guards (archived blocks run controls; Processing/Cancelling/Uploading hide delete which would 409; terminal-failure shows retry; Completed shows export). Server stays authoritative — every 403/409/404 becomes toast + `invalidateQueries(projects.lists())`.
- **Retry = `POST .../processing` (new run)**, not the legacy `retryActiveProcessingRun` (uncertain semantics for terminal-failed rows, would likely 404/409). Cancel = `cancelActiveProcessingRun` (needs only projectId) behind `ConfirmDialog`. Export = deep link to `/projects/:id/exports` (creation/download UX belongs to Task 033; inventing a format choice would be presumptuous). Delete has no reason field because v1 `DELETE` takes no body — audit is server-side (subject + correlationId); typed-name confirmation enforced client-side.
- **Columns honor the bundle honestly**: duration/progress-%/review-count are not in the `Project` schema, so those cells render em-dash + explanatory tooltips (no fake precision). Progress/activity/name/created sorts all map to server (`progress`→`updatedAt` + column tooltip "approximate ordering" per the task's edge case). Target-language/date-range refine the fetched page in memory (never re-slice server pages, R2); review-state filter omitted (no data to filter on — a control would fabricate).
- **R4 via param absence**: default `active` sends no `archived` param (backend default excludes); `archived`→`archived=true`, `all`→`archived=all`. `status`/`ownerId` sent via narrow cast — bundle documents only page/pageSize/sort/sortDir but `ProjectsController.List` accepts them.
- **Tenant-empty has no creation CTA**: Task 022 owns the wizard; a link would 404. Filtered-empty gets a working Clear action.
- **E2E navigates via SPA link** (`dashboard-stat-link`), never `page.goto` post-login — full reload drops the memory-only session by design.
