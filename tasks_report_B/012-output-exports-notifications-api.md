## Decisions Made
- **Superseded split honored:** target file header says 012 is superseded by 012A+012B; implemented both halves and all three validation filters (`OutputExportApiTests`, `NotificationsApiTests`, `OutputNotificationsApiTests`) rather than only the combined file.
- **Two incomplete codes, both live:** combined says `OUTPUT_INCOMPLETE`, split says `EXPORT_INCOMPLETE`. Added both (409). Guard in `RequestAsync`: snapshot incomplete + `!allowPartial` → `OUTPUT_INCOMPLETE` when no `OutputAsset` exists (output-Partial path) else `EXPORT_INCOMPLETE` (segment-incomplete path), both with `{completeness,isPartial,missing,offerPartial}` in message details. Tests assert either code for the no-output case.
- **Export retention stays 24h:** split says 7d but `IdempotencyRetention.ExpiryFor` maps `/export`→24h and `IdempotencyFilter` owns replay; kept 24h (single-row replay proven, expiry duration not asserted). Documented in code comment.
- **Download is 302, not 200 JSON:** combined R3 mandates 302 redirect; split allows either. Changed `ExportsController.Download` to `Redirect(url)` (302 + Location) with `export.download` audit; tests use `WebApplicationFactoryClientOptions{AllowAutoRedirect=false}` and assert Location + fake-storage TTL ≤15 min. Legacy `OutputController.Download` stays 200 JSON (separate route, unchanged contract).
- **Project vs export 404 split:** `RequireProjectAsync` keeps 403 for cross-tenant projectId (matches Task 010 convention); export-id mismatch converts Forbidden→404 via `GetOwnedAsync`; output aggregate returns 404 for project mismatch (its service owns 404, no leak). Tests cover each path explicitly.
- **No new projector for notifications:** extended `NotificationProjector` (explicit tenant filter, unreadOnly/count/read-all) instead of a parallel service; controller is thin over projector. No admin bypass per 012B (diagnostics aggregates own admin views).
- **Output URLs best-effort:** `OutputService.EntryAsync` catches all storage/ownership failures and degrades to fallback state with null URL (never throws, never leaks keys); issuance TTL is `SignedUrlPolicy.DefaultExpiry` (15 min). `URL_EXPIRED` triggers only when storage messages contain "expired" (re-issue by re-calling download).
- **Profile allowlist minimal:** `ExportProfileValidator` permits letters/digits/`-`/`_` ≤64, lowercases; rejects `..`/`/`/`\`/NUL and other punctuation with 400. No fixed profile set (format is the allowlist; profile is a variant).
