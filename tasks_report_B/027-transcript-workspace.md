## Decisions Made
- **Generated-client shapes win:** task shorthand `.../select-version`+`.../manual-version` mapped to bundle ops `selectTranscriptVersion` (`{expectedVersion, selectedVersionIds:[versionId]}`) and `editTranscript` (`{expectedVersion, text}`) via `apiClient`; backend DTOs use `ExpectedSelectionVersion`/`VersionId` (integration tests send `expectedSelectionVersion`), a bundle↔controller drift documented for 028/backend, not fixed here (no generated-code edits, no backend scope).
- **`queryKeys.transcript` as first-class scope:** `all=['projects','detail',id,'transcript']`, `list=[...,'list']`, `detail=[...,'detail',seg]` so prefix invalidation cascades from `project.detail`; registry extended only for workspace-invalidating events, `stage.progress` intentionally omitted (too chatty).
- **Single logical query, no per-row fetch in list:** `useTranscript` pages `listSegments(pageSize=200, max 10 pages)` then hydrates `getSegment` detail only for rows lacking text/versions; `VirtualizedSegmentList` receives hydrated array via props and never calls `apiClient` (R6 test asserts `data-rendered<100` for 1000 rows).
- **Player slot placeholder:** `TranscriptEditor({playerSlot?})` defaults to timing-only `transcript-player` (`data-seek-target/position/seek-version/active-segment` + `transcript-player-scrub` range); Task 030 mounts compact `MediaPlayer` via `playerSlot` and adopts `useTranscriptPlaybackStore.requestSeek/reportPosition` without API change.
- **409 never overwrites:** `isSelectionConflict({code,status})` branches on `SELECTION_CONFLICT`/409; select-409 discards pending selection + refetches via `invalidateTranscript`, manual-409 preserves `draft` as dirty + refetches, never auto-resubmits; stale banner `transcript-stale-banner` cleared only by `transcript-stale-refresh`.
- **Deleted-segment UX:** `TranscriptEditor` effect detects `selectedId` missing after refetch, moves to `segments[0]` and pushes error toast `Segment was removed...`; beyond-range `findActiveSegmentId` returns `undefined` (highlight cleared, no crash).
- **Sanitization/audit:** texts render as React plain text only (no `dangerouslySetInnerHTML`, banned by eslint); version meta shows `provider/model/version` only; attribution stays server-side via session token (no user id sent).
- **E2E tab workaround:** `ProjectLayout` still renders from `EMPTY_WORKSPACE_STATE` (transcript tab is a disabled span, no `project-tab-transcript` testid); E2E clicks the tab when present else does `history.pushState('/projects/prj_1/transcript')+popstate` (SPA, no reload, preserves in-memory session) — production route exists regardless of tab disabled state.
