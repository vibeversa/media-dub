## Decisions Made
- **Peaks endpoint as raw `apiFetch` (drift-safe):** no `waveform-peaks` route exists in `openapi.v1.json` (Task 004 created artifact types only, no HTTP surface). Frontend defines `GET /projects/{id}/media/waveform-peaks[?resolution=]` via `apiFetch` in `useTimelineMedia.ts:fetchWaveformPeaks`, matching `MediaPreviewGenerator.BuildWaveformPeaksJson` shape `{durationMs,sampleRate,resolutions:{64,256,1024}}`. Uses raw fetch so the Task 014 drift gate (generated client vs bundle) stays clean; backend can add the route later without client change.
- **Playback URL from `downloadOutput` (bundle-frozen):** `fetchPreviewMedia` calls `apiClient.downloadOutput` (`GET /projects/{id}/output/download` → `{downloadUrl,expiresAt}`), the only signed-URL descriptor in the bundle. URL lives in query cache + `<video src>` only (referrerpolicy no-referrer imperatively, never logged, never in errors).
- **`queryKeys.timeline` as child of project detail:** `all=['projects','detail',id,'timeline']`, `media=[...,'media']`, `peaks=[...,'peaks'(,resolution)]` so prefix invalidation from `project.detail` cascades; keeps Task 017 R1 scan green (no inline `queryKey:` literals).
- **Read-only grep-gate is affordance-specific:** banned regex `/retime|trim-handle|trimhandle|duration-input|durationinput|duration-edit/i` over `src/features/timeline` excluding `__tests__` (see `timeline.test.tsx:exposes no manual timing`). Bare `.trim()`/`durationMs` state remain legal; waveform uses `.replace(/^\s+|\s+$/g,'')` for style reads to avoid even the substring.
- **Shared store bridges transcript:** `useTimelinePlayerStore.requestSeek/reportPosition/jumpToIssue` forward into `useTranscriptPlaybackStore` (one-way import, no cycle) so compact `<MediaPlayer compact>` in `TranscriptEditor playerSlot` needs no second element; compact hides frame/segment/volume/rate/PiP/fullscreen controls.
- **No hex in canvas:** `Waveform.tsx:drawWaveform` reads `var(--color-brand)` / `var(--color-neutral-status-bg)` via `getComputedStyle` with `var(...)` fallbacks (no `#888`), satisfying `check:no-hex`.
