## Decisions Made
- **Cost canonical lives in `features/cost`, settings untouched:** Task 035A excludes settings screens (035B owns them), so the new `cost/` module duplicates (not deletes) the superseded-035 `settings/` cost helpers. `ActivityPage` was rewired to `cost/`; legacy `settings/CostSummary|QuotaBanner|useCostQuota|quotaDismiss|types` remain for backward compat until 035B cleans the split. No `SettingsPage`/`usePreferences` changes.
- **Advanced gating via session permissions only:** `canViewAdvanced=hasAdminPermission(useAppStore(s=>s.permissions))` where `ADMIN_PERMISSION_ALIASES=['admin.manage','diagnostics.view','admin:read']` in `src/app/session/permissions.ts`. Workspace `allowedActions` not consulted here because `AuditTimeline` does not fetch workspace (avoids extra aggregate + N+1); E2E `ME_BODY` already includes `admin.manage` so the toggle stays visible there. Forbidden renders `activity-advanced-forbidden-{id}` text placeholder, never `activity-error`.
- **Partial = background refresh with data, not error toast:** `showPartial=!isPending&&isFetching&&data!==undefined&&rawItems.length>0` in `AuditTimeline` (`activity-partial/partial-refresh` invalidates `queryKeys.activity.all(projectId)`); same pattern in `CostSummary` (`cost-partial/partial-refresh` calls `refetch()`). Stale-error path (`isError&&data`) kept as `activity-stale/activity-refresh`. No polling added; SSE registry already invalidates.
- **Pagination bounds DOM instead of virtualization lib:** Backend `GET .../activity` is page-based (`{page,pageSize}`, `ACTIVITY_PAGE_SIZE=20`, `hasMore/total`), never full fetch; table renders one 20-row page so DOM is bounded (equivalent to windowing at this size). No `react-window` dependency added; documented in component docblock.
- **Provider units = priced segment-count mirror:** `CostBreakdown.providerUnits` is `guessSegmentsFromDuration(durationMs)` (`ceil(durationMs/5000)`, 10 fallback, 2000 clamp) — the same input to `estimateRunCostUsd` — rendered as `cost-provider-units` (`"{n} segments (planning figure)"`). Never a guarantee; label + `cost-estimate-note` cover R3.
- **403 cost = forbidden, not error:** `CostSummary` maps 404→`cost-unavailable`, 403→`cost-forbidden` (`Cost visibility restricted`, `authorized roles only`, no retry/bypass), else→`cost-error` with retry. `reservedUsd` stays `undefined` (no backend hold field); `deriveQuotaState` still maps `reserved` when positive.
