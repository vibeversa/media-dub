## Decisions Made
- **Stability = per-run rows, per-project voice (documented decision)**: `speaker_voice_assignments` unique is `(tenant,run,speaker)`, so each run gets its own row; the voice (`VoiceProfileId`) is project-stable via prior-run copy (`LoadPriorProjectAssignmentAsync` ordered by `CreatedAt` desc). Same-run retry returns existing (`IsNew=false`) unless the override voice differs (then delete+insert replacement in one transaction). `PolicyHash` is frozen at creation (retries keep history); new-run copies get a fresh hash. Rationale: matches task hint verbatim while preserving the unique index and audit trail.
- **Inventory = TTS union with language + privacy gates, synthetic mock fallback only for zero-config**: `BuildCandidatesAsync` queries `IDescriptorStore.GetCandidatesAsync(Tts)`, keeps rows passing `PolicyChecker.CanUseProvider` + `IsCompatible(RoutingRequest(target,0,0))`, drops descriptors whose `SupportedLanguages` excludes the target, unions non-empty `VoiceInventory` entries (deduped per provider+voiceId), resolves `Type` from existing `VoiceProfile` rows else `InferVoiceType`. Empty union with any configured inventory → `PROVIDER_CONFIGURATION_ERROR` (edge: no inventory for language). Empty union with zero configured inventories → synthetic stock `mock-voice-1/2/3` for `DefaultProvider` (keeps default mock deployments flowing; real misconfiguration still fails loudly).
- **Cloned detection = persisted row wins, else `cloned-` prefix**: `VoiceType` comes from the existing `VoiceProfile` row when present; new rows infer via `InferVoiceType` (`cloned-` case-insensitive → `Cloned`, else `Stock`). Rationale: descriptors carry only `VoiceCloning` capability flags, not per-voice types, and no `VoiceProfile` seeder exists yet; naming gives hermetic determinism while persisted rows stay authoritative.
- **Override key = exact `Speaker.SpeakerKey` ordinal; multi-provider override prefers `DefaultProvider`**: `settings.voiceOverrides` parsed case-insensitively for the section name but ordinally for speaker keys/voiceIds. Unknown override → `PROVIDER_CONFIGURATION_ERROR` fail-fast (R4). Multi-provider same voiceId → `DefaultProvider` first, then provider ordinal (deterministic).
- **Consent split = `CONSENT_REQUIRED` for evidence/status/scope/voice-relation, `POLICY_DENIED` only for jurisdiction**: `ConsentService.ValidateForVoice` throws `CONSENT_REQUIRED` for null/incomplete/revoked (`Status!=Granted` or `RevokedAt!=null`)/scope-miss/voice-mismatch, and `POLICY_DENIED` only when `Jurisdiction` mismatches `ProcessingPolicy.ResidencyConstraint`. Null policy skips jurisdiction (fail open there, still fail closed on consent). `ScopeCoversProject` = `*` or contains project `N`/`D` (case-insensitive). `VoiceAssignmentService.ValidateClonedUse` adds the `CloningEnabled` kill-switch check before delegating (stock voices skip everything).
- **Live revocation blocks even idempotent returns; artifacts never deleted**: `AssignAsync` re-validates cloned consent before returning an existing row; revoked → `CONSENT_REQUIRED` (new segments blocked to review per edge case) while prior assignment/artifact rows remain (immutable, never deleted except the override-replace path which swaps one row for another in-transaction).
- **Worker output = assignment id (no media artifact)**: `VoiceAssignmentWorker` completes with `[assignmentId:N]` in both `CompleteAsync` output and `StageCompleted.OutputArtifactIds` for traceability; the barrier counts completions, not artifacts. Failures go via `StageWorkerFailure.TryFailAsync` (fail-fast, `no-review` per DAG); no retryable `StageFailed` path (consent/policy/config errors are permanent; transport rethrows).
- **Barrier stays saga-owned (024–026 precedent)**: worker/service never touch `BarrierService`; `StageGraph` already defines `VoiceAssignment` per-speaker prereq `Diarization` (`all-units`), and `WorkDispatcher.DispatchSpeakerWorkAsync` seeds `ExpectedUnits=speaker count` — zero saga changes.
