## Decisions Made
- **Expanded `DecideAsync` signature vs task minimal**: task lists `DecideAsync(tenant,project,run,canonicalArtifactId,ct)` but lease-fenced `Complete`/`Skip` (020 pattern) requires `executionId/owner/token`; implemented `DecideAsync(tenant,project,run,canonicalArtifactId,executionId,owner,token,ct)` with empty-canonical auto-resolve. Worker passes `InputHash N` when present else `Empty`.
- **Mock-only adapter gate**: only `ISourceSeparationProvider` registered is the mock (no keyed/azure/openai/google/local separation adapters exist in 021). Resolver non-Mock results fall back safely with reason (no call, QC + Completed) instead of throwing; `failOnSeparationError=true` throws `PROVIDER_CONFIGURATION_ERROR` for that case. Real byte-returning adapters land later without changing this contract.
- **Mock bytes materialized as canonical copies**: `SeparationResponse` carries provider-side ids only, not bytes. Dialogue/background artifacts publish the FFprobe-validated canonical bytes (distinct logical rows, dedup may reuse `ContentObject`), with `{providerDialogueId,raw/normalized/threshold,semantics,canonicalHash}` in `metadata_json`. Documented as pending real byte contract.
- **Fallback = Completed + note + warning, not Skipped/Failed**: per task decision — disabled/auto-no-background → `Skipped` (no QC, no execution row); low-confidence/permanent/transient-exhausted → `Completed` with `NoteFallbackAsync(SEPARATION_FALLBACK,reason)` + `QualityResult(PassWithWarnings/SEPARATION_FALLBACK/Warning)` + `ProviderExecution(QualityBelowThreshold/mapped outcome)`; first output id is always the selected dialogue/canonical for VAD. `failOnSeparationError=true` rethrows (low-confidence throws `PROVIDER_FAILED`, invalid response throws `PROVIDER_INVALID_RESPONSE`) so the shared failure path fails the run.
- **Transient retry within logical budget in-service**: transient = `HttpRequestException/TimeoutException/SocketException/IOException` or `ErrorCodeException` with `PROVIDER_RATE_LIMITED/TIMEOUT/QUOTA_EXHAUSTED/FAILED`; retries up to `Retry:PerStageMaxAttempts[SourceSeparation]` else `LogicalStageMaxAttempts` (1..10 clamped), then falls back (or rethrows when fail-on, preserving transport-retry vs Fail via `StageWorkerFailure`). `OperationCanceledException`/`LeaseLostException` always propagate; storage `IOException/Http/Timeout/Socket` propagate unwrapped (transient), other storage failures wrap as `STORAGE_UNAVAILABLE`.
- **No new migration**: reuses `artifacts`/`content_objects`/`artifact_parents`/`stage_output_artifacts`/`provider_executions`/`quality_results`/`stage_executions`; `SEPARATION_FALLBACK` is a QC/stage-note code (not a public `ErrorCodes` entry, which stays at 29 codes).
- **`StageExecutionService` additions instead of raw SQL in service**: `SkipAsync`/`NoteFallbackAsync` keep all lease-fenced SQL in one class; `CompleteAsync` output untouched by fallback note.
