## Summary
Implemented on-demand durable exports independent of the core DAG: 7 deterministic generators (`Srt`/`WebVTT`/`JSON-timeline`/`speaker-metadata`/`transcript`/`translation`/`quality-report`, UTF-8 LF) over an immutable selected-version snapshot, plus `ExportService` (request → worker generation → `Export` artifact + `ExportArtifact` link + `CompletenessJson` + `export.create/complete/failed` audits, ownership on every call, 15-minute downloads) and `ExportWorker` on the `export` queue. The controller now accepts kebab-case formats and serves completed + partial runs (latest `Completed` preferred, else latest `Failed/Cancelled/ManualReviewRequired` with `isPartial:true`); zero segments fails with `EXPORT_NOT_READY`. Tests: `ExportTests` 7/7 pass hermetically; regressions green.

## Decisions Made
- **Worker is plain `IConsumer<ExportJobRequested>`, not `BaseConsumer` (task-text deviation)**: the base consumer's `Cancelling/Cancelled → AckWithoutWork` gate would silently drop partial exports for cancelled runs, violating R5 (`failed/cancelled where data exists`). The worker mirrors `MessageDisposition` poison contracts itself (version/identity → `_skipped`, cross-tenant/missing → `_error`) but processes regardless of run status. Precedent: 019 `MediaIngestionWorker` is `IConsumer<MediaUploaded>`, not `BaseConsumer`.
- **Export artifact uses `StageType.Render` + `ArtifactType.Export` with empty parents**: there is no `Export` stage type; `Render` is the closest lineage stage. Parents are empty (per-segment lineage would require dozens of parent rows and validation sprawl); the auditable record is `metadata_json` (`schemaVersion/exportJobId/runId/format/isPartial/counts/sourceHash`), matching the 031/033 metadata pattern.
- **`ExportFormatParser` fixes a latent 018 bug**: the old controller used `Enum.TryParse<ExportFormat>` which rejects the documented kebab-case (`json-timeline`, `speaker-metadata`, `quality-report` → `DomainException`/400). The parser accepts kebab/underscore/space/case variants plus PascalCase (`format.ToString()` from the message) so controller and worker share one path.
- **`EXPORT_NOT_READY` maps to 409, not the task-text 400**: the frozen `ErrorCodes.StatusFor` catalog maps `EXPORT_NOT_READY → 409`; the catalog owns the mapping (same class of deviation as 030's `QC_BLOCKED` mapping). Zero segments and no-exportable-run both throw `EXPORT_NOT_READY`.
- **Completeness counts are segment-based, `sourceHash` falls back to `run.ConfigurationHash`**: no dedicated completion ledger exists; completed = transcript+translation present, failed = missing either, skipped = `Skipped` status, reviewCount = open reviews, `isComplete` = run `Completed` + zeros. `sourceHash` = earliest Valid `MediaAsset.ContentHash`, else `ConfigurationHash` (always present, never empty).
- **Running-job redelivery regenerates (resume-safe)**: generation is deterministic and publish creates new immutable artifact rows; the job points at the latest. `Completed` redelivery returns the existing artifact without regenerating; `Cancelled` produces no artifact (cancel endpoint itself is Task 035's scope).
- **No new migration, no new options section, no new queue**: reuses `export_jobs`/`export_artifacts`/`artifacts`/`content_objects`; idempotency stays 24h via existing `IdempotencyFilter` + `IdempotencyRetention.Export`; the `export` queue already existed in `QueueNames`/bus topology — only the extras-attachment branch was missing.
