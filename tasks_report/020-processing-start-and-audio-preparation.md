## Decisions Made
- **No `ICostGate.EstimateAsync` exists** (contract has only `CanProceedAsync`; Task 036 owns budgets). Cost preflight calls `CanProceedAsync(tenant,prospectiveRunId,"MediaAnalysis",1)` in the controller before any write (runId pre-generated and passed into the service); denial maps to 429 `QUOTA_EXCEEDED` per the task's documented decision. Quota counts active *runs* as the proxy for active projects (partial index enforces ≤1 active run/project, so the counts coincide).
- **Workers stay `BaseConsumer` (as specified) via two minimal shared fixes** instead of the 019-style `IConsumer` deviation: (1) `ShouldProcess` pre-claim filter — required because MassTransit delivers every `StageWorkRequested` to *all* consumers on `media.preparation`, so without it each worker would claim foreign stages and orphan Running executions; (2) post-Handle accepts `Completed`/`Failed` — the old `Running`-only check threw `LeaseLost` for every worker that actually completed work (latent 011 bug affecting all future stage workers).
- **No `ProviderExecution` row for audio prep** (task's own parenthetical allows stage metadata instead): no provider is involved, so args live in the canonical artifact's `metadata_json` (+ `ProcessRunner` logs + `OutputArtifactIdsJson` holding the artifact id).
- **Analysis artifact reuses `ArtifactType.FfprobeAnalysis`** with stage `MediaAnalysis` (no enum addition; content is ffprobe-derived duration/streams/plan). `needsSeparation = channels>=2` is a deterministic MVP heuristic; Task 021 owns real separation policy.
- **`Start` requires `MediaReady` strictly** (a `Processing`-with-no-active-run project gets media-not-ready 409, not a new attempt; retry/new-run semantics belong to Task 035). First-run `StartedAt` is null (`Pending`; the saga flips to `Running` on `RunStarted`). `PipelineVersion` fixed `1.0.0` (previous stub `"v1"` retired); the optional `StartProcessingRequest.PipelineVersion` remains ignored.
- **Disk check precedes download** using `MediaAsset.SizeBytes×2`, so `Disk_Full_Fails_Fast` needs only PG + mock (no MinIO/ffmpeg) and production never wastes a download when doomed.
- **`StorageQuotaGate` untouched** (upload-time storage quota stays 019's); start-time quota is active-run count.
