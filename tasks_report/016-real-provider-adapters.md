## Decisions Made
- **New sections, legacy fallback, no breaking change.** `Azure/OpenAI/Google/LocalInference` are separate `SectionName`s (follows `TransportOptions` pattern); adapters read new options first, fall back to `ProviderOptions.AzureApiKey/OpenAIApiKey/GoogleApiKey`; `ProviderStartupValidator` + `ProviderHealthTracker.ValidateConfig` accept either. Keeps mock-default boots green and existing `ProviderOptionsValidator` untouched.
- **Keyed DI preserves mocks as default.** Mocks stay non-keyed `AddSingleton<I*,Mock*>`; reals are concrete singletons + `AddKeyedSingleton<I*,Concrete>(azure/openai/google/gemini/local)` via factory to same instance. Workers future resolves via `GetKeyedService(providerName)`; no routing change (016 forbids it). `LocalInferenceProvider` also keyed for transcription/translation/TTS bridges.
- **Centralized HttpClient resilience.** Moved `providers` named client (retry 3 exp+jitter transient-only, breaker, 30s timeout) from `Api/Program` to `ProviderRegistration` so Workers gets it too; added dedicated `local-inference` client with mTLS primary handler. Removed Api duplicate to avoid double-retry stacking. `Infrastructure` adds `Microsoft.Extensions.Http.Resilience 10.0.0` (same as Api).
- **Hermetic JSON wire contracts, not binary.** Production would send audio binary/SSML; adapters send JSON artifact references (`{"artifactId"}`, `artifact:{id}`, multipart stub part for Whisper) and parse minimal JSON. Documented in adapter XML + README; keeps CI without paid calls and makes malformed/partial deterministic.
- **Classification split (transport vs quality vs quota).** `ThrowIfErrorAsync` maps 429→RateLimited (quota substring/header→QuotaExhausted), 408/504→Timeout, 4xx→Failed-permanent, 5xx→Failed-transient, 200-bad-JSON→InvalidResponse. `ToOutcome` maps Quota→RateLimited for health (no separate OutcomeClass), Config→PolicyRejected. `OutcomePolicy.Decide` in tests proves retry/fallback/review split (RateLimited retry+fallback, InvalidResponse fallback-only, Quality review-only).
- **`FailRate`-style determinism not reused; WireMock is source.** Real adapters have no scenario injection; determinism comes from stubs. Timeout uses `HttpClient.Timeout` (200ms) + WireMock `WithDelay(5s)`; external cancel propagates OCE (not mapped to Timeout) via `!ct.IsCancellationRequested` guard.
- **Idempotency everywhere TTS/translation.** OpenAI/Azure TTS already had it; added to Azure-Translator + Google-Translate/Gemini/Google-TTS via `BuildIdempotencyKey(run:N,stage,scope,attempt)` (same format as `ProviderExecutionRecorder`). Google STT excluded (STT not in R2 scope). Duplicate test asserts same `contentId` + `Idempotency-Key` header in `LogEntries`.
- **Poller generic, adapters expose batch.** `ProviderJobPoller` takes `Func<string,CT,Task<JobStatus>>` so tests inject WireMock-backed `GetBatchStatusAsync` (Azure/OpenAI) or in-memory counters (Google/Local which have no batch API). Defaults 10s/30min per spec; tests pass ms/sec. `FromStatusString` normalizes vendor strings; `Failed/Expired`→`PROVIDER_FAILED` (review if policy), timeout→`PROVIDER_TIMEOUT`.
- **mTLS minimal but real.** `LocalInferenceOptions.RequireMtls` + `ClientCertificatePath/Password[Secret]`; validator requires https+path; `ProviderRegistration` configures `local-inference` primary handler with `X509CertificateLoader.LoadCertificateFromFile/LoadPkcs12FromFile` (not obsolete `X509Certificate2` ctor, SYSLIB0057). `Protocol=grpc` accepted with `X-Sidecar-Protocol` marker; true gRPC owned by 043.
- **Secrets hygiene.** All keys `[Secret]` + `MaxLength(512)`; `ConfigurationHashCalculator` already strips `*key*`; adapter errors carry provider+path+status only (body preview 512 chars, no keys); `ProviderEndpointValidator` allowlists BaseUrls. No hardcoded secrets; tests use `"test"` keys + WireMock loopback.
- **WireMock path fix.** `WithPath("*/:recognize")` throws (must start `/`); use `/v2/*`, `/v3/*`, `/v1/models/*`, `/v1/text:synthesize`. `ProviderHttpHelper` made `public` for contract-test outcome mapping; test namespace collision fixed via `global::` + fully-qualified `Microsoft.Extensions.Options.Options` (bare `Options` resolves to `UnitTests.Options`); `Assert.Throws` sync for `ValidateConfig` (async needs `ThrowsAsync`).
