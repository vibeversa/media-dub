## Decisions Made
- **Fallback fires before burning retry budget** (deviation from the task's literal retry→fallback order): with deterministic providers a same-input retry is futile, so low confidence/invalid tries one compatible fallback first; still-low with attempts left throws `TranscriptionRetryableException`, else review. Terminal states match the task either way.
- **Fallback = second compatible Mock deployment**: the worker only holds the injected (Mock) adapter like `DiarizationWorker`, so `FindFallbackDescriptorAsync` returns a distinct invocable (`Mock`) descriptor — a different provider when configured, else a second Mock row; single-deployment setups skip fallback and go retry/review. Integration fakes use 1 vs 2 Mock descriptors to cover both paths.
- **Cost gate = Application-owned `IProviderCostGate`** (not `Infrastructure.ICostGate`, which would violate layering): `CanProceedAsync(tenant, Transcription)` pre-check, denial → `QUOTA_EXCEEDED`; per-unit reservation stays Task 36.
- **Idempotency key gains a per-provider suffix** (`{run:N}:Transcription:Segment:{id}:{provider}:{attempt}`): primary + fallback are two recorded calls in one attempt, and the recorder throws `CONFLICT` on same-key/different-hash, so the suffix is required for the fallback row.
- **Barrier stays saga-owned** (codebase truth over task text, same call as 022/023): the worker never calls `BarrierService` (no existing worker does; saga records on `StageCompleted`/`StageFailed`/`StageReviewRequired`); `Barrier_Correct` covers counts via `BarrierService` directly.
- **Retryable failures publish `StageFailed(IsRetryable=true)` manually** (`FailAsync` + event) instead of `StageWorkerFailure` (which hardcodes false): this lets the saga redispatch the next attempt and defer rate-limit codes via `DelayedRetryErrorCodes`; `TranscriptionOptions.MaxAttempts` bounds budget with `Retry:PerStageMaxAttempts[Transcription]` override.
- **No new migration**: reuses `transcript_versions` (+`(ProjectId,SegmentId)` index), `artifacts`/`content_objects`/`artifact_parents`/`stage_output_artifacts`, `stage_executions`, `provider_executions`, `review_items`, `run_stage_summaries`/`stage_unit_completions`.
