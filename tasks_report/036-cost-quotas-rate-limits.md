## Decisions Made
- **No new migration.** `cost_reservations`/`quota_usages` tables already exist (005/006); atomicity uses `pg_advisory_xact_lock(hashtext(project))` inside the reserve transaction (serializes per-project inserts under `ReadCommitted`), not schema changes. `Reconcile/Release` use conditional `UPDATE ... WHERE state='Reserved'` (idempotent double-calls safe).
- **Project total = `SUM(Reserved.reserved) + SUM(Reconciled.actual)`.** Spec says "sum(reserved for project)"; reconciled actuals keep counting after hold→actual conversion so spend never drops on reconcile (prevents reserve→reconcile-low→reserve-over loop). Documented on `ReserveAsync`.
- **Rate fail-open vs quota/cost fail-closed (task edge).** `RateLimiter` Redis outage → allow + warning log (never blocks pipeline); `QuotaService.CheckStorageAsync` DB outage → deny (`false` + error log → `QUOTA_EXCEEDED`); throwing quota/cost paths propagate as 500 `INTERNAL_ERROR` for alerting. `TenantFairnessGate` dispatch check fail-opens (advisory only); `CostGate` fail-closes (deny). All catches exclude `OperationCanceledException` (cancellation propagates) and quota storage excludes `Domain/App` exceptions (validation stays 400).
- **Fixed-window Lua, not sliding token-bucket.** `INCRBY + EXPIRE 60 + compare` is atomic across replicas, needs one key, and auto-expires (no leak on crash). Documented as 60s fixed-window admissions; `concurrency` enforced as per-minute admissions for the same leak-freedom reason (not a live gauge).
- **Fairness segment cap is PG counts, provider cap is Redis.** Durable executions must be correct across restarts (PG), while provider admissions are ephemeral (Redis). Dispatcher keeps its existing global cap check plus the new per-tenant fairness check; both map to frozen `concurrency-exhausted`.
- **Stub replacement via registration, not call-site rewrites.** `Translation/Tts/ProcessingController/WorkDispatcher` keep their frozen `ICostGate/IRateGate/IProviderCostGate` calls (now real); new `CostService` deps are optional (`= null`) so the 310 unit + PG pipeline suites construct unchanged and behave identically when unwired. `IProviderCostGate` stays Singleton (for Singleton `ProviderResolver`); real gates are Singleton via `IServiceScopeFactory` (no captive Scoped deps).
- **Preflight is check-only at start.** Segments don't exist at `POST processing`, so `PreflightAsync` estimates from validated media duration (1 segment/5s, 100 chars each, deterministic) and throws `QUOTA_EXCEEDED` without writing hold rows; per-segment holds happen in Translation/TTS workers.
- **Storage behavior change on DB outage documented.** `MediaIngestionService` previously saw a thrown outage → 503 `STORAGE_UNAVAILABLE`; with `QuotaService` it now sees deny → 429 `QUOTA_EXCEEDED`. Both deny; the new code preserves the frozen `bool` contract while failing closed.
