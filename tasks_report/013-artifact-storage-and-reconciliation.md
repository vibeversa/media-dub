## Decisions Made
- **No `Pending` reservation rows.** Spec text says reserve Pending then commit, but domain has no transition methods (private setters) and two-phase Pending adds crash windows without benefit: upload-then-single-commit-transaction gives the same observable guarantees (failed commit → no Committed rows + orphan blob for reconciler, proven by `Failed_Commit` test). Pending/Orphaned/Deleted states still fully used (Committed→Orphaned by reconciler, Deleted reserved for Task 37).
- **Existence checks after upload (not before).** Parent/execution existence is validated inside the commit transaction, after the blob upload. This wastes upload bandwidth on bad references but is required for the spec edge "Failed DB commit → blob remains orphan": fail-fast-before-upload would leave no blob to reconcile. ID shapes (empty Guids, extension format) still fail fast before any I/O (caught by offline validation tests with strict fakes).
- **Concurrent duplicate loser deletes its blob then reuses.** Same bytes in different runs produce different keys (run in key), so the loser's post-upload unique-violation path best-effort deletes its duplicate key before reusing the winner's `ContentObjectId`. Leftover on delete failure is covered by the reconciler.
- **Outbox "same tx" via caller, not service.** `Application` has no MassTransit reference by design; `PublishAsync` owns the single DB transaction for Content+Artifact+parents+StageOutput, and callers publish `StageCompleted` afterwards in the same consumer context so the bus outbox captures it. Documented on the class; no `IPublishEndpoint` leaked into Application.
- **Checksum compare only when authoritative.** `GetStorageChecksumAsync` returns SHA-256 only; ETag MD5/multipart returns null and skips comparison. Never re-downloads to hash (only `VerifyIntegrityAsync` downloads, explicitly for QC/render revalidation).
- **`IStorageInventory` split from `IArtifactStorage`.** Listing is required for reconciliation but the 7-method interface is frozen exact; the S3 adapter implements both, the reconciler depends on inventory, tests stub listing for deterministic 25h age (real S3 `LastModified` is always now, untestable otherwise) while delegating quarantine to real MinIO.
- **Retention hook semantics.** `CanDeleteContentObjectAsync` uses `LastReferencedAt` (not `CreatedAt`) + `retentionDays`, refcount over all artifact rows, returns false when missing/foreign. Hold blocking documented: with zero refs there is nothing to join, so active artifact/project holds only matter while refs exist (already false); Task 37 owns physical deletion.
- **Extension fail-fast fix from tests.** Offline strict-fake test exposed extension validated after a DB read; promoted `NormalizeExtension` to public and validated before hashing/upload.
