## Decisions Made
- **Score persisted 0..1, computed 0..100 (documented normalization)**: task formula yields 0..100 but `SyncResult.SyncScore` validates 0..1, so `BuildSyncResult` stores `clamp(score/100)`; out-of-range scores clamp (150→1.0, negative→0.0). No migration or entity change.
- **Onset fixed at 0, silence at 0 (documented, not invented)**: placement never shifts here (Task 30 owns lead-lag); no silence detector exists yet, so the penalty term is wired at 0 with the formula complete. `rateDelta=|rate-1|`, `stretchExcess=|factor-1|`.
- **Prosody/stretch fit direction is `actual/target` (physics-correct)**: rate/factor >1 speed up too-long audio, <1 slow down too-short; `AdjustedDuration=round(actual/factor)`. This differs from 028's TTS pre-adjust formula (`target/estimate`, preserved untouched for TTS); timing fits generated audio to the window, so the correct ratio applies. Noted in code docs.
- **Rewrite reuses stored alternatives (no provider call)**: alternates beyond the candidate budget fill the rewrite budget deterministically via `DurationEstimator`; an LLM rewrite call would need a new capability/cost gate and break boundedness. Review path preserves current selection (reviewer decides); acceptable path creates a new selected `TranslationVersion` (priors unselected in-tx) when the winner text changed (R5).
- **Stretch cap is symmetric `[1/1.15, 1.15]`**: covers both shorten and lengthen; required factors outside skip stretch entirely (logged as invariant `LogError`, no violation) and route to review. `BuildStretchArgs` validates the single-filter 0.5..100 range (fails fast); the 1.15x timing cap is enforced upstream by `ClampStretch`/`Plan`.
- **Stretch previews recorded as Mock/Tts executions**: no Timing capability exists, so model `ffmpeg-atempo-1` + `fallbackReason="timing-stretch"` + template `timing-stretch-v1` carry the audit; idempotency key `{run:N}:TimingOptimization:Segment:{segment:N}:stretch:0:{attempt}`. Artifact is `GeneratedAudioPreview` + `GeneratedAudioArtifact(IsPreview=true)` with exact FFmpeg args in metadata; audio selection surfaces via execution output ids (entity has no `IsSelected`).
- **Zero-duration → `PROVIDER_INVALID_RESPONSE`, no stretch (edge)**: both pure `Plan` and `OptimizeAsync` (DB + probe paths) throw before any stretch; probe undecodable/zero/no-audio-stream likewise. `TimeoutException` rethrows for transport retry; `INTERNAL_ERROR` stretch failures keep final audio and continue to review.
- **Service final is Acceptable* or Manual only**: intra-call budgets are fully consumed per call, so out-of-tolerance finals have no attempts left → `ManualReviewRequired` (review, never fail the run). `SyncRetryable` exists in pure `Classify` for saga-level budgets and is unit-tested, but the service does not emit retryable outcomes (deterministic inputs would loop forever).
- **`OptimizeAsync` extends the task's 5-arg shape with lease fencing** (`attempt,executionId,owner,token`, 024–028 precedent): required for claim/complete/review fencing and idempotent redelivery (`Completed`/`ManualReviewRequired` + existing `SyncResult` returns stored outcome). No new migration (reused `speech_segments`, `translation_versions`, `generated_audio_artifacts`, `artifacts`/`content_objects`, `sync_results` latest-wins replace in-tx, `stage_executions`, `provider_executions`, `review_items`).
