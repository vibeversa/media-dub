# Media Fixtures

Deterministic synthetic fixtures for test tiers (E2E smoke, recovery, signal/
golden). Generated by `scripts/generate-fixtures.sh` (bash, requires ffmpeg).
Re-run the script to regenerate; it is idempotent (skips existing outputs
unless `FIXTURES_FORCE=1`). All fixtures are synthetic tones/test patterns:
no PII, no secrets, no licensed content.

Canonical audio fixtures are 48kHz stereo s16 to match the pipeline canonical
form (see Task 20). `low-quality.wav` is the exception: mastered at 8kHz mono
then upsampled to 48kHz to exercise the low-quality path.

## Golden thresholds

- Duration tolerance: ±100ms (`ffprobe` duration vs the table below).
- Loudness targets: web −16 LUFS / −1 dBTP, broadcast −23 LUFS / −1 dBTP
  (`LoudnessTarget.WebDefault` / `Broadcast`); raw sine fixtures assert the
  sane-signal band (−70..0 LUFS, peak < 0 dBTP) rather than the normalized
  target, with ±1 LU tolerance where loudnorm is applied.
- Timing: preferred ±50ms, max ±100ms, max rate change 15%, max stretch 1.15x
  (`TimingWindow` defaults).
