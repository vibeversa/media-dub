## Decisions Made
- **Queue = `ai.gpu` per `WorkQueueRouter`, not task-text `ai.provider` (documented deviation, 022/025 precedent)**: `WorkQueueRouter.QueueFor(VoiceGeneration)` returns `ai.gpu` (GPU-backed generation taxonomy); `WorkDispatcher` sends via the router, so a worker attached only to `ai.provider` would orphan messages. Added `MassTransitConfig.AttachOrchestration` `ai.gpu` branch (`ConfigureConsumers` when extras exist); `ShouldProcess` filtering keeps the now-6 consumers on `ai.provider` + N on `ai.gpu` safe. Worker doc records the deviation.
- **Config = all three keys (`MaxAttempts`+`EstimatorEnabled`+`PreviewEnabled`)**: task Context says `Tts:{MaxAttempts=3,EstimatorEnabled=true}`, Instructions say `Tts:{MaxAttempts=3,PreviewEnabled=true}`. Implemented all three (defaults 3/true/true) so both statements hold; `EstimatorEnabled=false` forces rate 1.0 + raw text (no SSML), `PreviewEnabled=false` makes `isPreview=true` fail fast `VALIDATION_FAILED`.
- **Mock-only synthesis with Application-local WAV (dependency direction)**: `Application` cannot reference `Infrastructure.Providers.Mock` (dependency-free direction), so `TtsService.ResolveAudioBytes` uses `audioBase64` test hook when present else local `GenerateSineWav(response.DurationMs)` (16kHz mono 440Hz, byte-identical per duration, mirrors `MockDeterminism`). `ProviderResolver` still routes `Tts` capability; non-Mock resolved providers throw `PROVIDER_CONFIGURATION_ERROR` (024–027 precedent). Real byte-download for cloud TTS stays out of scope (adapters are JSON-hermetic in 016).
- **SSML always wraps when estimator enabled (even at 1.0)**: `ssml=BuildSsml(text,rate)` when `EstimatorEnabled`, else raw text. Rationale: deterministic `ssmlHash`/`requestHash` + `promptHash` recording stays stable, and `Estimator_Reduces_Attempts` asserts `<prosody rate="85%">` in the provider request. XML-escaped (`&<>"'`), whole-percent (`100%`/`85%`/`115%`), clamped rate.
- **Idempotency = execution-terminal reuse + per-attempt dedup**: `TryReturnIdempotentAsync` returns latest `GeneratedAudioArtifact` for `(run,segment,isPreview)` when execution is `Completed`/`ManualReviewRequired` (output id from `OutputArtifactIdsJson`, review id when relevant). `PersistAndCompleteAsync` also checks `(run,segment,isPreview,attempt)` before insert and re-completes instead of duplicating (crash between publish and `Complete` leaves at most one row per attempt; `ArtifactService` dedup may reuse `ContentObject` but `Artifact` + `GeneratedAudioArtifact` rows stay distinct per preview/final).
- **Budgets = `MaxAttempts` gates retryable→review, fallback only for undecodable**: primary `PROVIDER_INVALID_RESPONSE` (empty validation or `TryValidateAsync` null) records `ProviderInvalidResponse` then tries one fallback Mock call (same `_tts` instance, `:fallback`-suffixed idempotency key, `fallbackReason="tts-fallback"`); fallback success+valid persists with `fallbackUsed=true`, else `TTS_QUALITY` review + `ManualReviewRequired` + `tts.review_total`. Retryable codes (`RATE_LIMITED`/`PROVIDER_RATE_LIMITED`/`PROVIDER_TIMEOUT`/`PROVIDER_QUOTA_EXHAUSTED`/`PROVIDER_FAILED`) rethrow while `attempt+1<MaxAttempts` (worker publishes retryable `StageFailed` for saga deferral), else review with `budgetExceeded=true` + `tts.budget_exceeded_total`. `QUOTA_EXCEEDED` (cost gate) never retries (permanent `TryFailAsync`). Transport (`HttpRequestException`/`TimeoutException`/`SocketException`/`IOException`) rethrows into transport retry. `VALIDATION_FAILED`/`PROVIDER_CONFIGURATION_ERROR`/`PIPELINE_INVARIANT_VIOLATION` fail fast.
- **Validation = temp-file probe with audio-stream gate**: `TryValidateAsync` writes bytes to `Path.GetTempPath()/dubbing-tts-*.wav`, calls `IFFprobeService.ProbeAsync`, requires `DurationMs>0` plus ≥1 `CodecType==audio` stream (case-insensitive); probe throw/zero-duration/no-audio → null (invalid path). Temp deleted in `finally`; lease-loss before commit discards bytes (published orphans covered by reconciler, `ArtifactService` orphan semantics).
- **Parents = translation artifact only**: TTS artifact `parents=[translationArtifact]` when found via `metadata_json` `segmentId:N` scan (latest wins); voice assignment has no artifact (assignment id traceable via `VoiceProfileId` on `GeneratedAudioArtifact` + `ProviderExecution.VoiceProfileVersion`). Metadata JSON carries `schemaVersion/runId/segmentId/sequence/targetLanguage/voiceId/provider/model/durationMs/estimatedMs/prosodyRate/ssmlHash/template/isPreview/fallbackUsed/translationVersionId/translationArtifactId/attempt` (no text/SSML/secrets, only hashes).
