## Decisions Made
- **Queue follows code truth, not task text phrasing**: worker lives on `ai.provider` per `WorkQueueRouter.QueueFor(Translation)` (same call as 022–025); `ai.provider` now hosts Diarization + Transcription + ContextBuild + Translation, so `ShouldProcess` is mandatory.
- **One-call primary plus at-most-one fallback (no per-candidate loop)**: `ITranslationProvider.TranslateAsync` already returns primary plus alternatives in one call (Mock returns 2 alts); "else loop" is satisfied by truncation to `MaxCandidates` plus a single fallback call for low quality. Documented in service docs; future streaming providers can extend the loop without changing the budget/selection contracts.
- **Fallback is first compatible Mock descriptor by Id (not distinct provider)**: transcription's `d.Provider != primary` filter can never fire in Mock-only deployments (all rows are Mock), which would make "fallback exhausted → review" untestable and leave single-deployment low quality with only a retryable path. Translation picks the first compatible Mock descriptor (deterministic `Id:N` order) and records it with a `:fallback`-suffixed idempotency scope, so primary and fallback are distinct rows even when the adapter is the same Mock; single-descriptor still attempts one fallback call (deterministic same-output, then review). Idempotency scopes include model (`Segment:{id}:{provider}:{model}[:fallback]:{attempt}`) to avoid `CONFLICT` on same-request/different-response.
- **Timing ratio incorporates the ideal**: `adjusted = (targetChars/sourceChars)/ideal`, `timing = 1-min(1,abs(adjusted-1))` with `IdealRatio` table en→es 1.0, en→de 1.1, default 1.0 (documented on `IdealRatio`). Rationale: German averages ~10% longer, so parity would penalize correct German length; unknown pairs assume parity so timing never rewards truncation. Zero/negative source yields 0 (no divide-by-zero).
- **Glossary overrides score (documented rule)**: when any candidate is compliant, only compliant candidates are considered; otherwise all are considered. Tie-break inside the considered set is score → semantic → naturalness → provider → model → text → index, all ordinal/deterministic.
- **Budgets select best-so-far, review only when empty**: candidate overflow truncates, token/cost overflow after a call keeps primary best-so-far and skips fallback, wall-clock timeout with candidates keeps best-so-far while timeout with zero candidates throws `PROVIDER_TIMEOUT` (retryable, worker redispatches). "No candidate" review creates a `ReviewItem` with null version and `Empty` ids (the only path with empty ids); all quality-low reviews persist the winning version first so timing optimization still has alternatives.
- **Cost uses dual enforcement**: pre-call `IProviderCostGate.CanProceedAsync` (frozen allow-all until Task 36; denial → `QUOTA_EXCEEDED` with no provider call) plus per-response `EstimatedCostUsd` accumulation against `MaxCost` (Mock reports 0, so the cap never fires spuriously but is exercised when providers report cost). Same dual pattern for tokens (usage sum, else `chars/4` estimate).
- **Window ref recorded via artifact lineage + metadata (no schema change)**: `TranslationVersion` has no context column, so R2 is satisfied by `Translation` artifact `parents=[transcript?,context?]` plus `metadata_json` fields `contextWindowId/contextArtifactId/transcriptArtifactId/transcriptVersionId/usedContext`; the worker result also returns `UsedContext/ContextWindowId`. Rebuilds never delete versions/artifacts (priors unselected in-transaction, old artifact rows remain history).
- **Barrier stays saga-owned (024/025 precedent)**: worker/service never touch `BarrierService`; Translation gating reuses existing `StageGraph` (`Translation` per-segment, prereq `ContextBuild`, `all-units-or-review`) plus `ArePrerequisitesCompleteAsync` with zero saga changes. Missing-context segments still complete (with warning) so one unassigned segment never stalls the barrier; empty source fails fast `VALIDATION_FAILED` (permanent, no review).
