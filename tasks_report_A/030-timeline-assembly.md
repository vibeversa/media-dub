# 030 — Timeline Assembly Report

## Status
COMPLETED

## Summary
Implemented run-scoped deterministic timeline assembly (`TimelineAssemblyService` pure `BuildTimeline`/`BuildJson` plus lease-checked `AssembleAsync`, and `TimelineAssemblerWorker` on `media.render`): each selected generated segment placed at its source `StartMs` with the generated audio duration (silence gaps preserved, no shifting), intentional overlaps kept via shared `OverlapGroup` sets, overlaps without a shared group rejected with `PIPELINE_INVARIANT_VIOLATION`, and entry ends beyond `sourceDurationMs + 100ms` rejected with `QC_BLOCKED` before any artifact commit. The canonical timeline JSON (schema v1, alphabetically sorted keys, entries by StartMs then Sequence) is persisted as a `Timeline` artifact with `parents=selected audios`. Tests: `TimelineTests` 4/4 hermetic pass; regressions green.

## Decisions Made
- **Queue `media.render` per router, not task-text `control.orchestration` (code truth)**: `WorkQueueRouter.QueueFor(TimelineAssembly)=MediaRender`; `control.orchestration` is pub/sub saga control and never carries point-to-point work (025 precedent). Documented in the worker docs; dispatcher sends via the router so no dispatcher change was needed.
- **Scope `Project` per `StageGraph`, not task-text `Run` (code truth)**: the `TimelineAssembly` node is `(Project, single, ["TimingOptimization"])` and `WorkDispatcher.DispatchSingleWorkAsync` emits `(Project, projectId D)`; the worker strictly requires `ScopeType.Project`. Documented in the worker docs.
- **Worker name `TimelineAssemblerWorker` per task literal** (not `TimelineAssemblyWorker`): no prior timeline worker existed, so the task's exact name was adopted for file/class/logger.
- **Overflow `BLOCKED` maps to `QC_BLOCKED`**: `BLOCKED` is not in `ErrorCodes`; `QcBlocked` is the only blocking code, preserving the task's overlap-vs-overflow distinction (`PIPELINE_INVARIANT_VIOLATION` for invalid overlaps, `QC_BLOCKED` for overflow). Both fail lease-fenced with no artifact commit (validation runs before `PublishAsync`).
- **Selected audio = timing output first, final fallback**: per-segment latest Completed `TimingOptimization` output id wins (covers stretch-preview winners); else latest `GeneratedAudioFinal` artifact found by `segmentId:N` metadata substring (028 pattern). Durations resolve via `GeneratedAudioArtifact` sharing the chosen artifact's `ContentObjectId`, else latest segment row, else `actualMs/durationMs/duration` metadata parse; unresolved → `ARTIFACT_UNAVAILABLE` (or skipped-omit when status is `Skipped` case-insensitive).
- **Source duration = earliest Valid `MediaAsset`, else max segment `EndMs`** (diarization precedent); zero segments yields an empty valid timeline. Background = separation execution second output id when present, else latest `BackgroundStem`, else null (timeline carries it as nullable metadata; mixing in 031 resolves bytes).
- **Overlap validity = shared-group-set intersection on placed audio intervals**: multi-group segments valid when any group intersects; strict `>0ms` overlap with empty/disjoint sets fails. Micro-overlap adjacency (022 truncates ≤100ms to no-group) is therefore invalid if placed audio still overlaps — faithful to the task's "overlap without group → fail" with no invented tolerance.
- **Canonical JSON = `SortedDictionary` keys + StartMs/Sequence/SegmentId entry order**: satisfies "sorted keys" deterministically under `JsonSerializerDefaults.Web` (camelCase, no indent); byte-identical for identical inputs (asserted in test). Top-level extends the task's `{SchemaVersion, RunId, Entries}` with `sourceDurationMs/backgroundArtifactId/skippedSegmentIds/overflowToleranceMs` to satisfy the skipped-marking edge; entry adds `sequence` to implement the required sort.
- **Stage commit stays worker-owned**: `AssembleAsync` keeps the task's 4-arg shape `(tenant,project,run,ct)` and persists the artifact only; the worker does lease checks + `CompleteAsync` + `StageCompleted` (SegmentBuilder precedent). Duplicate redelivery is safe: terminal `Completed/Skipped` executions return before calling the service, and every new assembly creates a new immutable `Artifact` row preserving history.
- **`MassTransitConfig` MediaRender branch required**: no worker previously routed to `media.render`, so without the new `AttachOrchestration` branch the registered worker would never attach (028 `ai.gpu` precedent). `ShouldProcess` keeps the now-4-endpoint sharing safe. No new migration, no new config keys (reused `speech_segments`, `segment_overlaps`+`overlap_groups`, `generated_audio_artifacts`, `artifacts`/`content_objects`/`artifact_parents`/`stage_output_artifacts`, `media_assets`, `stage_executions`).
