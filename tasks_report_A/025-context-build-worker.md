## Decisions Made
- **Queue follows code truth, not task text** (same call as 022–024): worker lives on `ai.provider` per `WorkQueueRouter.QueueFor(ContextBuild)`; `control.orchestration` is pub/sub for saga control messages, never point-to-point work. `ScopeId` likewise follows code truth (window id as dispatched) but also accepts a bare sequence number (dual-parse, 018 precedent).
- **Non-overlapping partitions only** (task allows overlapping but asks to document the default): overlapping windows would multiply units, complicate barrier accounting, and weaken translation lookups; partitions keep unit identity deterministic and artifacts maximally reusable.
- **Lazy materialization in the dispatcher** (the load-bearing bootstrap fix): no prior stage creates `ContextWindow` rows, so `DispatchWindowWorkAsync` would always find zero windows, the `ContextBuild` barrier would sit at `ExpectedUnits=0` (which `ArePrerequisitesCompleteAsync` treats as incomplete), and Translation would never dispatch — a pipeline deadlock. The dispatcher now calls the idempotent `BuildWindowsAsync` once when `ContextBuild` has zero rows, then enumerates and dispatches normally; the ctor param is optional so existing test harnesses compile unchanged.
- **Barrier stays saga-owned** (024 precedent): the worker never calls `BarrierService` (service initializes the summary; the saga records completions); Translation gating reuses the existing `StageGraph` prerequisite + `ArePrerequisitesCompleteAsync` gate with zero saga changes (R5).
- **Token estimate is literal `chars/4` floor on the exact persisted text** (char-count budgeting, no flooring drift), so R1 holds strictly on the default path; a lone over-budget segment is emitted whole with `overflow:true` (never truncated), token-driven breaks set `split:true`, all recorded in artifact metadata.
- **LLM failures propagate** (no silent concatenation fallback): the default path has no provider; operators opting into `UseLlmSummary` accept its failure domain. Only `Mock` is invocable (same adapter gate as diarization/transcription). `ProviderExecution` idempotency scope embeds the prompt-hash prefix (`Window:summary:{hash16}`, attempt 0) so content changes create history rows instead of `CONFLICT`s; there is no `SystemHash` column, so the system hash lives in artifact metadata + the request-hash input (R4).
- **Rebuilds never delete windows/artifacts** (rows update in place via `ContextWindow.Update`, old artifact rows remain as history); only stale `SegmentContextAssignment` links are reconciled, since assignments are pure derived data and duplicates would make translation lookups ambiguous.
- **Empty input yields zero windows without failing**; segments without a selected transcript are skipped with a count (their translation is 026's concern). Zero windows leaves Translation gated — 026 must decide the explicit Translation-skip for the all-failed case (same pre-existing pattern as silent-audio with zero segments).
