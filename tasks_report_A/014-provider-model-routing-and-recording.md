## Decisions Made
- **Model lives in config, not domain.** `ProviderCapabilityDescriptor` has no Model field; resolver returns `option.Model` for matching (provider,capability) else `{provider}-default` (mock→`mock-1` via synthesized path when Descriptors empty). Avoids domain migration for a routing label.
- **Compatibility flags default false in `ResolveAsync`.** Signature lacks format/feature flags, so routing checks language/size/duration only; workers needing wordTimestamps/diarization/cloning call `IDescriptorStore.IsCompatible` directly with a full `ProviderRoutingRequest`. Prevents false negatives from assumed requirements.
- **Empty language/format lists mean unbounded.** Config defaults `[]` and synthesized mock use `[]` (all languages/formats); `Max*=0` means unbounded. Lets mock-only defaults route with zero config.
- **Policy null fails closed to mock-only; missing DB policy synthesizes from `PrivacyOptions`.** Resolver falls back to `Privacy(External,Allowed,Residency)` + `Local=true`/`allow` strings when no `ProcessingPolicy` row, so offline/default tenants still route mock while unknown tenants cannot reach cloud.
- **Free-form `SensitivePolicy`/`VoicePolicy`/`RetentionOverride` hashed, not blocked.** No allowed sets exist in domain; blocking on unknown strings would false-deny. They enter `PrivacyHash` for audit; call-site workers enforce consent/retention semantics later.
- **`Enabled` missing key means enabled.** Only explicit `false` (ci-matched incl. `local` alias) excludes; new providers route without flag churn. Disabled-all yields `PROVIDER_CONFIGURATION_ERROR` (operator config, not tenant policy).
- **Priority lookup case-insensitive; unlisted sort last by enum name.** `RoutePriority` dict is `Ordinal` with lowercase keys, so resolver scans keys ci-equal to capability. Tiebreak by `Provider.ToString()` Ordinal is deterministic, not precedence (proven by `No_Hardcoded_Precedence` with `["openai","azure"]`→OpenAI).
- **Fallback budget = `1 + Retry:FallbackMaxAttempts`.** Each examined candidate (healthy pick or unhealthy/cost skip) consumes one slot; exceeding budget throws even if a later healthy route exists (`Fallback_Budget_Respected` uses 0→`PROVIDER_FAILED`). Cost-only exhaustion yields `QUOTA_EXCEEDED`; health exhaustion yields `PROVIDER_FAILED`.
- **Cost-gate exceptions treated as cost-skips (fail closed).** Prevents overspend on cost-store outage; degrades to `QUOTA_EXCEEDED` rather than crashing routing.
- **Health errorRate needs ≥5 calls; circuit opens after 5 consecutive failures.** Avoids single-failure flapping while matching spec (>20% last 100). `GetState.IsHealthy` ANDs runtime health with config validity for dashboards, but `IsHealthy()` (routing gate) stays runtime-only per spec separation.
- **Redis is mirror-only.** Writes fire-and-forget with 1h expiry, never read for routing; memory authoritative. Satisfies “Redis + memory” without cross-replica flakiness or test Docker dependency.
- **Recorder reconcile: same key + same hashes → existing id; same key + different hashes → `ConflictException` (409).** Prevents double billing on redelivery while surfacing true key reuse bugs.
