## Decisions Made
- **Separate `Providers:Mock` options, not nested in `ProviderOptions`.** Follows `TransportOptions` pattern (`SectionName="Providers:Mock"`), binds `Scenario/FailRate/FailWith/Behaviors` independently; `ProviderOptionsValidator` untouched so existing validation still passes.
- **Recursive `Behaviors` on same class.** `MockBehaviorOptions.Behaviors: Dictionary<string,MockBehaviorOptions>` (OrdinalIgnoreCase) satisfies both `Providers:Mock:Scenario` and `Providers:Mock:Behaviors:Transcription:Scenario` with one class/validator; nested values validated one level (scenario/failrate/failwith) to avoid infinite recursion.
- **Case-insensitive scenario + capability lookup.** Scenarios compared via `NormalizeScenario` (trim+lower) + `IsKnownScenario` OrdinalIgnoreCase; `Resolve` scans `Behaviors` keys OrdinalIgnoreCase (binder may replace comparer). Prevents `Transcription` vs `transcription` config churn.
- **`FailRate` semantics (deterministic, testable).** `async-job` always applies; `success`+`FailRate>0` injects `FailWith ?? rate-limited` when `SeededRandom(seedKey|failrate).NextDouble()<FailRate`; non-success +`FailRate=0` always fails (fixture determinism), +`FailRate>0` fails with probability `FailRate` else succeeds. Uses stable per-request seed so same input never flakes.
- **Throwing vs data scenarios.** Throw: `rate-limited→PROVIDER_RATE_LIMITED`, `timeout→PROVIDER_TIMEOUT` (after cancellable 50ms delay; cancelled CT throws OCE → same code via middleware), `malformed→PROVIDER_INVALID_RESPONSE`, `expired→PROVIDER_FAILED` (permanent), `quota-exhausted→PROVIDER_QUOTA_EXHAUSTED`; unknown→`PROVIDER_CONFIGURATION_ERROR` fail-fast at runtime + validator. Data: `low-confidence→0.35` (quality path, `AllowRetry=false` per 014 `OutcomePolicy`), `duplicate→success+mock.duplicate`, `partial→truncated+mock.partial`, `async-job→success+mock.job_id/polls`. TTS/separation/video translate "same bytes" into deterministic ids/hashes (DTOs carry no streams; `GenerateAudioBytes` exposes bytes for equality).
- **Unconditional mock DI.** Always `AddSingleton<I*,Mock*>` (not conditional on `DefaultProvider==mock`) so fallback stays explicit when reals land in 016; resolver's `RoutePriority` remains the switch. Default config (`DefaultProvider=mock`) routes to mocks with zero extra config.
- **Record `List<>` equality handled in tests, not impl.** DTO records hold `List<>` (reference equality), so `Same_Input_Same_Output` does deep field-by-field asserts (counts + per-element Start/End/labels/text) plus TTS `GenerateAudioBytes` byte equality; avoids false negatives from new list instances.
- **Fully-qualified `Microsoft.Extensions.Options.Options`.** Test file lives under `DubbingPlatform.UnitTests.*` where bare `Options` resolves to `DubbingPlatform.UnitTests.Options` namespace (CS0234); all `Create/DefaultName` uses fully qualified. `Unknown_Scenario` made `async` to satisfy xUnit1031 (no `.Result` blocking).
