## Decisions Made
- **Scope `Project` per code truth, not task-text `Run`**: `StageGraph` scopes `Render` as `(Project,single,[QualityControl])` with `DispatchSingleWorkAsync` emitting `(Project,projectId D)`; worker strictly requires `ScopeType.Project`. Queue `media.render` matches both text and `WorkQueueRouter.QueueFor(Render)`. No `MassTransitConfig` change (030/031 branch already covers `media.render` via `ShouldProcess`). Documented in worker docs (022/025/030/031/032 precedent).
- **Worker publishes both `StageCompleted` and `RunCompleted` (task-literal)**: `StageCompleted` feeds the barrier (`Render` summary); `RunCompleted` carries the new `OutputAssetId`. The saga's `MaybeCompleteRun` may publish a second `RunCompleted` with the same `OutputAssetId` — idempotent terminal signal, and `UpdateRunStatusAsync` guards with `WHERE status <> 'Completed' AND status <> 'Cancelled'`. Documented in worker docs.
- **QC-open routes to `ManualReviewRequired`, not `Failed`**: instruction 3 (`ManualReviewRequired`) wins over the edge-note shorthand (`fail fast with QC_BLOCKED`); the worker makes no FFmpeg call, marks the execution review-required, and publishes `StageReviewRequired` referencing the existing open review id (earliest `CreatedAt`). The `QC_BLOCKED` code is preserved in the blocking review's reason/history, so "no render + QC_BLOCKED" holds without failing the run.
- **`apad+atrim` pad added beyond the task's literal args**: task args show only `-shortest` (trim-only). Short dub audio would then trim video below source duration and fail tolerance; the worker pads short audio to the exact source video duration (`apad=whole_dur={src},atrim=0:{src}`) so `-shortest` lands within one frame. Recorded in artifact metadata; deviation documented here.
- **Stage metadata = `RenderedOutput` artifact `metadata_json`**: `StageExecution` has no metadata column, so exact `ffmpegArgs` + `copyVideo`/`reencodeReason`/`outputFormat`/durations/tolerance/fps live on the artifact row via `UPDATE artifacts SET metadata_json` (031 precedent), with parents distinct `[mixed+source?]`.
- **`aac` maps to `.m4a` / `audio/mp4` / container `m4a`**: native `aac` in MP4 container is the portable choice (`.aac` ADTS would break `mp4` players); `wav→pcm_s24le`, `mp3→libmp3lame 192k`, video audio always `aac 192k`. `mp4` without a source video fails `VALIDATION_FAILED` (fail-fast, no output).
- **`OutputController` unchanged**: `GET /api/v1/projects/{id}/output/download` already enforces ownership + deleted checks and issues `SignedUrlPolicy.DefaultExpiry` (15 min) URLs via `ArtifactService.GetDownloadUrlAsync` (404 `ARTIFACT_UNAVAILABLE` when no output, never 501). Task instruction 4 is satisfied as-is; `Download_Url_Works` proves the 15-minute policy at storage level.
- **`RenderService` is a singleton** (like `FFmpegMixer`): stateless, depends only on singleton `IFFmpegService`/`IFFprobeService`/logger. No new options section, no migration (reuses `artifacts`/`content_objects`/`artifact_parents`/`stage_output_artifacts`/`output_assets`/`processing_runs`/`dubbing_projects`).
